# Visual inspection V1 (iteration 21)

Scope: sign-in, sign-up, forgot password, first-run (fresh user), tour, app shell and sidebar, Settings, Integrations, bot settings panel.
Target: the mock-data demo stack only. Viewports 1440x900, 375x812, and 1920x1080 / 1280x800 for the shell. Screenshots are kept outside the repo; file names below are for reference only.

Method notes:
- The demo is shared with parallel walkers, so chat content, bot names and unread counts changed during the walk. Nothing below depends on those values.
- Touch emulation (`pointer: coarse`) is not available in this browser tool (the iPhone device preset still reports a fine pointer). Touch-target sizes were therefore not judged; at 375 px the audit only checked overflow and layout. Sidebar rows, the tour card and the integration chips carry `pointer-coarse` classes in code, which was not exercised.
- Both audit scripts were run on every surface. The contrast check in `layout-audit.js` reports ratios near 1.3 for text on transparent backgrounds in the dark theme; these were false positives (the text is clearly legible in the screenshots) and are not counted.

## Excellent as is

- Auth pages: clear hierarchy, one primary button, inline validation text per field with the password hint turning red, an error line that does not shift the layout, correct reflow at 375 with no overflow.
- App shell: fits one screen at 1280x800, 1440x900 and 1920x1080 with `pageScrollY` 0; the chat column is centred at 1920 and the sidebar, chat, Integrations grid and bot panel scroll inside themselves.
- Sidebar: tidy Pages list with small badges (unread, overdue, failed files), status line under bots ("Needs your answer", "Working..", "Waiting for approval"), truncated names carry the full name as a title, Create menu and account menu are short and labelled.
- Mobile drawer: 316 px panel with an obvious close control and a dimmed page edge, same rows as desktop.
- Cmd+K palette lists pages including Integrations and Settings, with a key hint footer.
- Settings: fixed-height dialog with four items on desktop and a section dropdown on the phone; the per-model data sharing disclosure is a native details element.
- Integrations: Connected, Popular, Finance and Social sections, filter chips, "Used by" avatars, one grid that grows to five columns at 1920 without overflow, single column at 375.
- Bot settings panel: short default view (name, description, notifications, skills), everything else under Advanced, 'Off in Settings' text where browser notifications are off, model picker labelled 'System model'.
- First-run: Chief's greeting plus the 'What should I work on first?' card, and the tour offered after the card is dismissed (pass 11); the tour works inside the phone drawer.
