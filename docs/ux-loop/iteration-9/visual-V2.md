# Iteration 9 visual inspection V2 (Inbox, Finance, Legal, agent chat)

Target: mock-data demo stack (web port 5381). Persona: Maya, first-time founder, Northwind Robotics.
Viewports: 1440x900 (all pages), 375x812 (Inbox, thread and attachment, Finance, Legal, chat), 1920x1080 (shell, Inbox, Finance, Legal).
Screenshots: `/tmp/uxloop9/V2/`. Both audit scripts were run on every captured state. The layout audit's contrast list reports ratios of 1.2 to 1.4 for ordinary text; the screenshots show readable text, so those are false positives and are not reported.
Not covered: touch-target findings (the browser could not emulate `pointer: coarse`, so none are claimed), 200% zoom, the Ask agent panel, Reply with draft, Cleanup with data (the demo had nothing to clean up).
The demo runs live agents, so unread counts and toasts changed during the walk (Inbox badge went 14, 12, 9).

## Excellent as is

- Inbox list after sorting: To do card with due dates in warning color, "Needs reply" and "Earlier" groups with unread counts, dense 57 px rows, sender/subject/date columns aligned, one-screen shell with the list scrolling inside (`inbox-sorted-1440.png`, `w-inbox.png`).
- Inbox at 375: compact pile list, search above the fold, readable truncation (`m-inbox.png`).
- Email header on mobile after the toast is gone: subject, sender, Reply (single high-emphasis button), Archive, Ask agent, More, previous/next and Close all in one row (`m-thread2.png`).
- Icon-only toolbar buttons have names and a tooltip on hover (`inbox-tip.png`). The attachment preview's icon buttons are named "Add to Data room" and "Download".
- Cleanup empty state is compact and offers one next action.
- Finance overview at 1920 and 375: KPI cards, period tabs, chart legend and cards read clearly; the 5 KPI cards reflow to two columns with no overflow (`w-fin.png`, `m-fin.png`).
- Finance Accounts page: clean totals, chart and grouped account lists (`fin-accounts-1440.png`).
- Legal Deadlines tab: due-in chips, date column, three consistent row actions (`legal-deadlines-1440.png`). Legal at 375 turns the table into labeled stacked rows with no overflow (`m-legal.png`).
- Artifacts: master/detail with list on the left, document preview and Download on the right (`artifact-1440.png`).
- Approval card hierarchy: question first, one filled Allow once, outlined Deny, answered state shown in words plus color ("Denied").
- Focus rings are visible on every tab stop tested.
