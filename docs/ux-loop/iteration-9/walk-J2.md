- Mercury "Allow changes" dialog now says "move money and change your Mercury accounts. It asks before each change." (earlier catalog hesitation fixed).

- Auto-sort with Undo toast, Stats page, the PDF preview with a summary and tags (d6, d7, d8).
- Legal Deadlines tab: overdue chip, "Due in N days", three clear actions per row, agent panel opens beside the list with the prompt already sent (l2, l3).
- New bot flow is minimal: one click, blank-slate greeting, name field focused.
