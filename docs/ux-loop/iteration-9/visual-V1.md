# Visual inspection V1 (iteration 9)

Group V1: sign-in, sign-up, onboarding, first-run tour, app shell and sidebar, Settings, Integrations, bot settings panel.
Target: mock-data demo stack only (web 5381). Screenshots are in `/tmp/uxloop9/V1/` (outside the repo).

Method notes
- Desktop: `agent-browser` at 1440x900, 1920x1080 (shell) and 1280x800 (Settings fit). Dark theme and a light-theme pass.
- 375x812 was run with Playwright (`hasTouch`, `isMobile`, `pointer: coarse` confirmed true), because `agent-browser set device` does not turn on coarse pointer. Touch-target numbers below were measured in that mode.
- Both audit scripts (layout-audit.js, geometry-audit.js) were run on each state. The audit's "lowContrast" list (ratios around 1.3 on nav labels) looked like a false positive from transparent backgrounds and is not reported. Its "deadSpace" hits on chat paragraphs were also false positives.
- Other inspector sessions share the same demo user, so chat content and sidebar state changed during the walk. Findings that depend on that are marked.
- Fresh user created for the onboarding and tour pass: `walker-v1-<n>@northwind.example.test` (invented; password not recorded).
- BLOCKED: every Connect button (Gmail, Google Calendar and the rest) needs real OAuth; not attempted. The "model" onboarding step does not exist on this stack (system model, no OpenRouter key), so only the "What do you want me on first?" and Connect-your-apps steps were walked.

## Excellent as is

- Landing, sign-in and sign-up: one primary action, 460px form, inline "At least 8 characters." hint only where it matters, both themes clean, no horizontal overflow at 375.
- Touch targets in the phone shell: with coarse pointer emulation every visible control in the shell, drawer and chat (header, message actions, composer buttons) measured at least 44px; the only misses are the switches in V1-10.
- Phone layout: no horizontal overflow on landing, sign-in, shell, drawer, Settings or Integrations at 375.
- Settings: fits one screen at 1280x800 (dialog 720px in 800px) and 1440x900, with inner scrolling; Esc closes it and focus returns to the account button; on phone it becomes a full sheet with a select for section nav.
- Privacy and approvals: one switch per area, new-user confirmations on, plain labels.
- Memory sits under Advanced; the Models and Voice pages state their purpose in one line and start with the provider list.
- Account menu: five short items, destructive item separated, "Take the tour" present.
- First-run tour: clear highlight ring on the real element, 1/9 counter, Back, Skip tour, one sentence per stop; it waits for the focus question and Connect cards as designed.
- First-run focus question and Connect-your-apps cards in chat: four lettered options, answer collapses to a checked row, reply links to Finance, Investors and Data room, then two Connect cards.
- Empty Inbox state: compact, one sentence, one button ("Connect mail").
- Integrations: Connected section first with a "Connected" label (words plus color), categories, search, one page, custom connection dialog compact and focused on the URL with Advanced collapsed.
- Light and dark parity on the shell, Settings and Integrations (apart from V1-01).
