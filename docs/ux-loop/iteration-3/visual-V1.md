# Visual critique V1 (iteration 3): auth, onboarding, tour, shell, Settings, Apps, bot settings

Target: mock-data demo stack only (web 127.0.0.1:5381). Method: layout-audit.js and geometry-audit.js at 1440x900, 375x812 (and 1920x1080 and 1280x800 for the shell), screenshots read by eye, tab order, menus, dialogs. Screenshots: /tmp/uxloop3/V1/. Session names uxl3-V1, uxl3-V1b (fresh user "Walker Vee", invented), uxl3-V1c. The demo password was passed from the credentials file straight into `fill` and never printed. Audit contrast flags (ratio 1.2 to 1.4 on most elements) are artifacts of transparent backgrounds and were ignored; contrast was recomputed against resolved backgrounds.

Not tried: Light theme (system is dark), real OAuth connect (BLOCKED, any "Connect" button leads to a real provider), the onboarding "model" step (the demo is pre-configured; a fresh user is never asked to pick a model, only "What do you want me on first?").

## Excellent as is

- Sign in and Sign up (1440 and 375): one column, 48px fields, clear labels, primary button full width, errors in words with role=alert, correct tab order, visible focus ring on links, fits one screen.
- Mobile drawer: the closed sidebar is `inert` (not in the tab order), and the drawer opens with scrim and a close button.
- Onboarding in chat: the "What do you want me on first?" card with A-D options and the inline Gmail / Google Calendar Connect cards turn the first run into one conversation. After answering, the card collapses to the chosen answer.
- Apps page: the Connected / Find an app / Popular grouping, status chips with text plus color ("Connected"), "Open Finance" jump links, and category filters. Full width on a phone with one card per row.
- Bot settings panel on mobile (full-screen sheet with close) and on desktop (side panel that resizes the chat, no page scroll).
- Shell at 1920x1080: sidebar, centered chat column and pinned composer; no dead bands.
- Models blurb ("They already have one, so change this only to use another AI company or your own key") is honest and useful.
