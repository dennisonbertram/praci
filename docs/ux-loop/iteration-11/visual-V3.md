## Excellent as is

- Data room list: failed rows say why ("This file isn't a readable PDF.") and offer Delete on the row; path bar, folder tree and "Add files" menu (Upload files, From email, From Box) are clear and compact.
- Data room mobile: flat folder picker with full paths, inline Filters, and a preview dialog with AI summary, parties, amount and tags.
- Touch targets measured with pointer: coarse at 375 on Data room, Contacts and Artifacts are all at least 44px; Artifacts shows the trash button on touch (hover only on desktop).
- Contacts: clean table, whole-row hover and click, edit dialog with clear labels and a separated Delete.
- Artifacts: grid, list and split-view with clear type and version badges.
- Command palette: grouped results (Mail, Contacts, Documents, Chats, Artifacts) with highlighted terms and chat snippets; empty state lists pages.
- Keyboard: Data room tab order is logical, with the folder tree and the list as single tab stops.
- No page scroll at 1280x800, 1440x900, 1920x1080 on any of these pages; inner panels scroll.
