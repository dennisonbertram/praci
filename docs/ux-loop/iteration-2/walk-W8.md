# UX walk W8: older Inbox and Data room stories

Session uxl2-W8, mock-data demo stack (web 5381), 1440x900 unless noted. Walker: Claude (Sonnet). Date 2026-10-20.

Scope: STORY-INB-001..040 and STORY-DRM-001..044 without an "Updated 2026-10-20" note, Retired skipped. That is 25 Inbox stories and 19 Data room stories (44 in total).

Method notes (read these before trusting a verdict):
- Logged in as the demo founder with the credentials file; the password was never printed.
- The demo has two mock Gmail accounts ("Founder mail", "Sales mail") plus "Mail needs reconnect" and "Mail rate-limited" spaces. Steps counted below are actual clicks/keystrokes of the walk, not counting waits.
- Some early screenshots were not viewable by me (image reads returned nothing). For those steps the verdict rests on DOM snapshots and measured values, and I re-took and viewed the key ones later (inbox list, thread dialog, search, compose with attachments, forward). Every visual claim in the findings table comes from a screenshot I looked at.
- Stories that need seeds the demo does not have (failed send, new mail arrival, a pending mail approval card) are BLOCKED, not failed.
- The Data room list loads slowly after navigation (see W8-07), so several waits were 4 to 12 s.
- I changed demo state: sent 5 mock replies/forwards, archived and restored a row, uploaded 7 small invented PDFs, renamed/moved/deleted some of them, created folder "W8 Advisors", and toggled AI data sharing off and back on. The AI toggle is on again.

## Praise (observed)

- Inbox: pile tabs, account tabs and the thread dialog read cleanly. "3 earlier messages" with one-line expandable history fixes the old miscount (INB-008). Undo works for Archive, Reply all and Discard, each time restoring text exactly. Back button and deep link behave exactly as expected (INB-038).
- Hide amounts now masks the Inbox list preview and message body, and the menu helper says "finance, chat and email" (INB-034).
- The attachment menu in the message dialog lets Maya put a mail attachment in the Data room in one click ("Add to Data room" then disabled "Added"), versus the five steps the catalog describes (INB-024/016).
- Data room: search result highlights, "No results / Search looks for these words" wording, removable filter pills with accessible "Remove filter" names, "New folder…" with an "Inside" selector, and the empty-space drop zone are all clear. The Data room agent answered the lease question correctly from the stored text.
- No horizontal page overflow at 390 px on Inbox or Data room; geometry audit at 1440 reported only the sidebar agent-row title/time width differences (intentional).
