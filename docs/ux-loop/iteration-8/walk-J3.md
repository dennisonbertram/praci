# Walk J3: phone width (375x812), core journeys

Target: mock-data demo stack (web 5381). Session uxl8-J3. Screenshots: /tmp/uxloop8/J3/.
Touch emulation: Chrome launched with `--blink-settings=primaryPointerType=2,availablePointerTypes=2,primaryHoverType=1,availableHoverTypes=1`. Verified `(pointer: coarse)` and `(hover: none)` both true, so `pointer-coarse:` classes applied. Targets below 44 px were also hit-tested with `elementFromPoint` before logging, because several visible boxes (checkboxes, switches, table rows) have a larger invisible hit area.
Caveat: the demo account was shared with other walkers during this run (Chief and Inbox agent chats changed under me), so some sidebar statuses moved between looks.
