# Walk J2: long journeys for raising and operating (iteration 8)

Walker session uxl8-J2, mock-data demo stack (web 5381, API 3308), 1440x900, no touch emulation. Screenshots are in /tmp/uxloop8/J2/. All stories were walked as Maya with the shared mock founder account. Other walkers use the same account, so Chief's chat and the sidebar contain messages and bots that are not mine; findings that depend on those are marked.

## Caveats
- The demo stack went down for about 90 seconds at 22:56 and came back reseeded, so my first Data room uploads were lost. Investors showed four stacked errors during the outage (J2-09).
- The agent-browser `find role ... click` helper misfired twice (clicked the wrong button). Those misfires are not product findings.
- Page loads on Finance and Integrations took 10 to 25 seconds while several walkers were active. Treat J2-15 as unconfirmed under load.

## Praise (observed)
- Legal Deadlines tab: overdue first, red "Overdue by 4 days", "Due in N days", clause quote under each row, Done and Dismiss on every row. Sidebar badge cleared on Done (l02, l03).
- Money approval card in the Mercury agent: one sentence with amount, payee and account, Details, Allow once / Deny, then "Approved" and a plain statement that the money has not moved (m04, m07).
- Honest agent answers: Mercury agent refused an unknown payee and listed the only recipient; Data room agent said one file was still being indexed; Finance agent said where to enable writes.
- Schedule review card names the cadence, next run and prompt (b17).
- Integrations Mercury page: Allow changes confirm dialog is precise (i07). New bot panel selects the name and autosaves with a "Saved" tick (b06, b08).
