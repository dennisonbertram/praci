# UX visual inspection V2 (iteration 5)

Group V2: Inbox (list, piles, digest, cleanup, thread, attachment preview), Finance (overview and sub-pages), Legal, agent chat with approval cards.
Target: mock-data demo stack (web port 5381), user Maya Chen (Mock), dark theme. Screenshots are in `/tmp/uxloop5/V2/`.
Viewports: 1440x900 (all pages), 1920x1080 (shell, Inbox, Finance), 375x812 (Inbox, nav drawer, thread, Finance, Legal, agent chat).

Limits of this run
- Touch emulation did not work in this browser tool (`set device "iPhone 16"` still reported `pointer: coarse` false and 0 touch points, and it forces 393x852). Per the owner decision, no touch-target finding is reported. 375x812 was tested as a plain narrow viewport.
- The demo is shared with other inspectors, so sidebar counts, spaces and "failed" toasts changed during the run. Some agent failures (model key rejected, connection timeout) come from the demo environment, not from the UI.
- To reach an approval card I answered the AI-sharing consent card in the Northwind Inbox agent chat (mock data only) and asked the Inbox agent to draft a reply to a mock sender. I did not press Send on the card.
- Cap table, Data room, Contacts, Artifacts, Settings, Integrations were not inspected (other groups).

## Excellent as is

- Inbox thread dialog and attachment preview: clear header, Reply is the one filled button, preview has "Add to Data room" and "Download", Escape closes preview then thread and focus returns to the exact row.
- The mail approval card: From, To, body, one filled "Send", a plain "Discard", and an "Edit" link; "Needs approval" is stated in words. Also fits cleanly at 375px.
- Mobile Legal: the 7-column contract table turns into labelled stacked cards, with sticky tabs and no horizontal overflow.
- Mobile navigation drawer: same content as the desktop sidebar, scrim visible, badges preserved.
- Inbox piles ("To do" and "Needs reply") after AI sorting is allowed: checkboxes, due labels, one-line summaries, dense rows at 57px.
- Finance overview: five KPI cards with units and basis lines ("3-mo avg, after revenue", "Not in runway · 1 unpriced"); the figures agree across overview, Runway and Accounts (cash $1,633,221, runway 24.2 months, stablecoins plus other crypto $105,250).
- Runway page: "Count crypto" toggle with its consequence stated beside it.
- Legal Deadlines: overdue marked in words and colour ("Overdue by 5 days"), dates right-aligned.
- Layout fit: no page scroll at 1440x900, 1920x1080 or 375x812 on any inspected page (pageScrollY and pageScrollX were 0; long content scrolls inside the main panel).
