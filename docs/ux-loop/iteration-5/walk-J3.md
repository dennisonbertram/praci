# Walk J3: phone width (375x812) sweep

Target: mock-data demo stack (web port 5381). Signed in as the seeded mock founder. Viewport 375x812, device scale 2, touch emulation on (`pointer: coarse`, `hover: none`, 5 touch points), set through CDP because `agent-browser set device` did not turn on coarse pointer. All touch-target numbers below were measured under that emulation. Console was clean (only Vite debug lines) on every screen. Screenshots: `/tmp/uxloop5/J3/`.

Note: the demo stack was shared with other walkers, so chats and toasts contained their activity (a pending mail approval, a Mercury approval toast, a second "Inbox agent" thread).
