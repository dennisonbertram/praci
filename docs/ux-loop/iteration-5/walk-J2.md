## Praise (verified in the browser)

- Data room: three PDFs were typed, summarised, tagged with parties and amount and filed within about 10 s, with a clear preview. Search highlights the matching snippet. Auto-sort shows "Sorted N items" with Undo.
- Data room agent: the answer lists the missing diligence documents and links the files it used. It spotted a $9M term sheet valuation against an $8M SAFE cap.
- Carta agent: SAFE conversion math was correct (4.375%) and stated its pre- or post-money assumption.
- Legal: tiles are now links, the Overdue tile opens a filtered list with "Show all 13", rows have Ask agent, Done and Dismiss, and Done has Undo. The failed-scan banner has a "Replace key" action.
- Mercury "Allow changes" dialog now says "move money and change your Mercury accounts. It asks before each change." The approval card title is a sentence: "Send $1,200.00 to Acme (Mock) from MOCK Checking ••1111?".
- Creating a bot takes one click: it opens with the name selected and a greeting. Settings autosave with a "Saved" check. Add skill offers New skill, Upload SKILL.md, From URL. `/boa` offers the skill and inserts a chip.
- Routines: the panel explains routines in one line, "Choose when it runs" replaces "Add trigger", and Save changes to "Saved" with a Run history.
- Finance page: five KPIs, burn chart, breakdown and upcoming bills fit one screen with no overflow (geometry audit: no page overflow, no spills).
