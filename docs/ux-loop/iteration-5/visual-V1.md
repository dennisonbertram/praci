# Visual critique V1 (iteration 5): auth, onboarding, tour, shell, Settings, Integrations, bot settings

Target: mock-data demo stack only (web 127.0.0.1:5381). Method: layout-audit.js and geometry-audit.js at 1440x900, 1920x1080, 1280x800 and 375x812; screenshots read by eye; tab order, menus, dialogs, Escape and focus return exercised. Screenshots: /tmp/uxloop5/V1/. Sessions: uxl5-V1 (seeded demo founder, password passed from the credentials file straight into `fill`, never printed), uxl5-V1b (fresh invented user "Maya Vee", signed up on the demo, used for onboarding and the tour), uxl5-V1m (375px, seeded user).

Touch measurements: `agent-browser set device` did not switch the pointer to coarse, so I held a CDP session open that enabled touch emulation (`pointer: coarse`, `hover: none`, maxTouchPoints 5) and re-measured at 375px. All "below 44px" claims below come from that mode. At fine pointer the same controls are not findings.

Not tried: Light theme (system is dark), real OAuth "Connect" buttons (BLOCKED, they leave for Google), the onboarding "model" step (the demo has a default model, so a fresh user is never asked to pick one), desktop-only controls. The Chief and sidebar data on the seeded account changed during the walk because other walkers share it (messages "Pay Acme ..." and "hello there" came from elsewhere).

Iteration 4 comparison: most iteration 4 V1 findings are fixed (list at the end). The findings below are new or still open.

## Excellent as is

- Landing: the logo mark is now clearly visible on the dark page (iteration 4 V1-12 fixed); one primary action, one quiet link; clean at 375.
- Sign in and sign up: three-field layout, labels above inputs, helper text only where needed, Show password and Forgot password now 44px high under touch, primary button full width. Sign in at 375 measured: inputs 327x48, primary 327x44.
- Onboarding: the "What do you want me on first?" card with A to D choices, the answered state collapsing to one row with a check, and the inline Gmail and Google Calendar Connect cards inside the chat. No modal, no separate wizard.
- Tour copy: step 7 now says "To approve emails and purchases before they happen, turn on Action confirmations in Settings", which matches what Settings shows (iteration 4 V1-03 resolved). Nine stops kept. The mobile sheet moves to the top when the target is at the bottom and keeps 44px buttons.
- Sidebar keyboard order: Search, Activity, Hide sidebar, Create, Pages, then every page row and bot in order; the iteration 4 trap at Hide sidebar is gone (14 Tab presses, no loop).
- Settings: fixed height across sections so the nav no longer jumps (iteration 4 V1-02 fixed), General now fits without scrolling (V1-11 fixed), Escape closes the dialog and focus returns to the user-menu button (V1-17 fixed), mobile uses a section select.
- Integrations desktop: Connected group first, search and category chips, clear "Open Finance" and "Open Inbox" shortcuts back into the app, "Used by" bot avatars.
- User menu: Task board, Settings, Integrations, Hide amounts (a checkbox item), Take the tour, Log out; short and in the order a founder reaches for them.
- Bot settings panel: fits one screen at 1280, 1440 and 1920 with no layout jump while skills load; Advanced, Export and the red Clear conversation are visually ranked correctly.
- Layout: no page scroll or horizontal overflow at 1280x800, 1440x900, 1920x1080 or 375x812.
