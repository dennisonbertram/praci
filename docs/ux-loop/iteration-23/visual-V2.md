# Visual critique V2 (Inbox, Finance, Legal, chat approvals and artifacts)

Inspector: uxl23-V2. Target: the mock-data demo stack only. Viewports: 1440x900, 375x812 (with touch emulation, `pointer: coarse` confirmed true), 1920x1080 for the shell. Screenshot files are in the session scratch folder (names only: `legal-375.png`, `legal-deadlines-375.png`, `approval-375.png`, `f375-category.png`, `f375-crypto.png`, `askagent-1440.png`, `artifact-ui-1440.png`, `focus-1440.png`, and others).

Method notes. Both audit scripts were run on each capture. The layout audit's low-contrast list reports ratios near 1.3 for sidebar labels that are plainly readable in the screenshots; it was treated as a false positive and no contrast finding is raised from it. Other sessions were using the same demo account at the same time, so extra bots ("New Bot", "New Bot 2"), extra sidebar sections and approval toasts seen in screenshots are not findings. No approval was answered and no payment was sent. Inbox AI sorting was allowed once so the sorted view could be seen.

## Excellent as is

- Inbox list: sticky header and tabs, the list alone scrolls (no page scroll at any viewport), sorted view with "Needs reply", "Show N more", the collapsed one-line To do card and its expanded state with an overdue date in red.
- Inbox on a phone: 44 px checkboxes, "..." per row, search under the tabs, every control in the full-screen thread measured at 44x44.
- Thread dialog: attachment chip with its own menu, a real PDF preview with "Add to Data room" and "Download" in its header, Escape returns to the thread and focus returns to the attachment button.
- Cleanup empty state: one line that says why it is empty, plus the next action.
- Finance overview, Accounts, Spend list and the Vendor page at 1440: dense, well aligned, one primary item per card, chart scale present; the Vendor chart has value labels that fit.
- Phone drawer: 46 px rows, clear counts and the red failed-file badge.
- Approval card: question first, collapsed Details, one filled primary button and a quiet Deny; composer shows "Needs your answer".
- Visible keyboard focus ring (3 px white) on list rows; tab order follows the page.

## Not covered

Cleanup with data, Digest, a real send flow, the secret-request card, file replace, and 200 percent zoom were not exercised. Piles and digest do not exist as named surfaces on this build (the sorted Inbox uses "Needs reply" and "Other mail today"). Real third-party sign-in was not attempted.
