# Visual inspection V1 (iteration 12)

Scope: sign-in, sign-up, first run (Chief welcome, first-question card, tour), app shell and sidebar, Settings, Integrations, bot settings panel.
Target: mock-data demo stack only (web 5381). Viewports 1440x900, 375x812, 1920x1080 (shell), 1280x800 (Settings).
Users: the supplied mock founder was not used; three fresh invented users were signed up on the demo (walker-v1a/b/d@northwind.example.test). Screenshots: `/tmp/uxloop12/V1/`.

Method notes
- `layout-audit.js` and `geometry-audit.js` were run on every page. The audit's "lowContrast" list reports 1.2 to 1.3 for light text on the dark theme (it cannot resolve the background), so it was ignored; contrast was re-measured from computed colors and from screenshot pixels. The geometry audit's `overflowSpills` of 124 px on chat bubbles are the hover toolbar and were not visible defects.
- Touch emulation is not available in agent-browser here (`pointer: coarse` stays false even after `set device`). Touch-target findings were therefore not filed; the phone targets measured 28 to 32 px (icons) and 32 px (rows) without emulation, which is unverified and probably different under `pointer-coarse:` styles.
- BLOCKED / not reachable: the "Connect a model" and "Connect your apps" onboarding steps (the demo has a default model and the fresh users skip straight to Chief); Gmail and Google Calendar "Connect" (OAuth, not attempted). Clicking "Connect" on Mercury connected the demo's mock Mercury immediately; that is the emulator, not a real account.

## Excellent as is

- Welcome, sign-in and sign-up pages: one primary action, clear errors, inputs keep their value, error text announced (`role="alert"`), no layout shift when the error shows, no scroll at 375 px.
- The app shell fits one screen at 1280x800, 1440x900 and 1920x1080; the chat, Integrations list and bot panel scroll inside their own regions.
- Sidebar rows truncate with an ellipsis and two-line names; folders show a count; "Skip to content" link exists.
- Settings dialog: fixed size, left nav on desktop, native select nav on phone, Voice folded into Models, Memory under Advanced, "Blocked" browser notification state explained.
- Destructive actions confirm ("Clear New Bot's conversation?" with the consequence in the text).
- Tour: nine stops anchored to the right controls at both widths, Skip tour leaves "What should I do first this week?" as a one-tap chip.
- Integrations on phone: compact rows, Show more, custom connection dialog with a clear Server URL field.
- Command palette (Search): grouped pages with keyboard hints.
