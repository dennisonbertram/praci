# Visual inspection V2 (iteration 4): Inbox, Finance, Legal, agent chat

Inspector: uxl4-V2. Target: mock-data demo stack (web port 5381), signed in as the mock founder (Maya, Northwind Robotics). Dark theme throughout. Viewports: 1440x900 (all pages), 375x812 (Inbox, thread, Finance, Legal, Chief chat), 1920x1080 (Inbox, Finance). Screenshots are in `/tmp/uxloop4/V2/` (outside the repo).

Method: each page and state was captured, then `layout-audit.js` and `geometry-audit.js` were run via `agent-browser eval`. I also used hover, Tab order, Escape, period switches, the Digest toggle, the preview dialog and a viewport resize. Every screenshot was opened and looked at.

Caveats:
- The demo account is shared with other walkers. Unread counts and the Chief and Investor Relations threads changed while I worked (for example another walker's "Send $1,200 to Acme" request). The chat findings below were seen in that live state.
- `layout-audit.js` reported a contrast ratio of about 1.3 for nearly every text node. That is a false positive on the dark theme (the script treats transparent backgrounds as white), so I did not log contrast findings. All text I looked at was clearly legible.
- The second-opinion script was skipped, as instructed.

## Excellent as is

- Inbox header stays sticky while the list scrolls inside its own panel, with no page scroll at any viewport I checked (L1, L7).
- Opening a message uses a focused dialog, and Escape returns focus to the exact row that opened it (I7).
- Attachment preview shows the PDF inline, with "Add to Data room" and "Download" as the only actions. This is a strong first-time-founder shortcut.
- Updates and Newsletters group mail by sender with counts. Mail moves to the right pile live after sorting finishes.
- Legal Deadlines puts the overdue item first, with a red "Overdue by 5 days" chip and date, so state is words plus colour (C3).
- Finance Runway page is exactly right: four KPIs, one chart (solid line to today, dashed projection), and a clear cash table that explains why crypto is excluded.
- Finance period switch (Week, Month, Quarter, Year) changes the chart and the headline, and the category breakdown bars are proportional.
- Mobile Finance and Legal reflow cleanly: KPI grid goes to two columns and tables become labelled cards, with no horizontal scroll (L6).
- Artifacts master-detail (list on the left, rendered content on the right, Download and expand) matches the category pattern (P1).
- Sidebar status text ("Needs your answer", "Working...", "Waiting for the model...") is words plus colour, in one predictable place.
- Tab order is logical and has a skip link; focus rings are visible (outline auto) on sidebar and page controls.
- Chat on mobile: "Thinking 4.2 s / Waiting for the model" is clear, and the composer swaps send for stop.
