# Visual critique V1 (iteration 4): auth, onboarding, tour, shell, Settings, Apps, bot settings

Target: mock-data demo stack only (web 127.0.0.1:5381). Method: layout-audit.js and geometry-audit.js at 1440x900, 375x812, 1920x1080 and 1280x800 (shell), screenshots read by eye, tab order, menus, dialogs. Screenshots: /tmp/uxloop4/V1/. Sessions: uxl4-V1 (seeded demo founder, password passed straight from the credentials file into `fill`, never printed), uxl4-V1b (fresh invented user "Maya Vee", signed up on the demo for onboarding, tour and Settings). Audit contrast flags (ratio about 1.2) are artifacts of transparent backgrounds and were ignored; contrast was recomputed against resolved backgrounds.

Not tried: Light theme (system is dark), any real OAuth Connect button (BLOCKED, leads to a real provider), the onboarding "model" step (the demo has a default model, so a fresh user is never asked to pick one), desktop-only controls ("Runs on").

Iteration 3 comparison: most of the iteration 3 findings are fixed (list at the end). The findings below are new or still open.

## Excellent as is

- Sign in and Sign up (1440 and 375): one column, 48px fields and buttons, clear labels, role=alert error with aria-invalid on both fields (new), red field borders, no layout shift when the error appears, visible focus rings, fits one screen.
- Loading after sign-up: the app skeleton (sidebar rows, composer) shows at once, then "Opening Praci..." (fixes the bare "Loading..." of iteration 3).
- Sidebar Pages list: all 8 pages visible with no clipping at 1280x800, 1440x900, 1920x1080 and in the 375 drawer; rows are 40px; section labels now contrast about 7:1 (iteration 3 had 2.9:1); closed drawer is inert and the drawer opens with scrim and a close button.
- Onboarding in chat: "What do you want me on first?" with A-D options, the answer collapses to a checkmark row, and inline Gmail and Google Calendar Connect cards follow; the tour waits for both.
- Tour popovers sit beside the sidebar and no longer hide neighbouring rows (except step 7 over the question card).
- Settings: five sections, active nav row now filled, strong segmented controls, on phones the tab strip became a "Settings" select, Voice names the selected provider ("ElevenLabs API key", "Connect ElevenLabs"), single "Allow GPT-6 Luna" switch replaces the two same-named toggles, aria-modal is set.
- Apps page: skeleton while loading, Connected / Find an app / Popular grouping, status chips in words and colour, "Open Finance / Open Inbox" jump buttons, category chips, "Add" for custom connection, scrolls inside its panel.
- Bot settings panel: side panel that resizes the chat on desktop, full-screen sheet on mobile; "Clear Chief's conversation?" confirm with Cancel focused and plain wording.
- User menu: "Hide amounts" no longer carries a duplicate explainer.
- Chat error banner ("The tools finished, but the model did not write a final answer. Rephrase the request and try again.") says what happened and what to do.
