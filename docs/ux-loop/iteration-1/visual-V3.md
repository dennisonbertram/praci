## Excellent as is

- Data room search with matches: highlighted excerpts and a sensible Relevance sort (dr-pilot.png).
- Processing strip details: progress bar plus stage counts ("Reading text 1, Tagging 5"), dismissible import notice, shimmer on the active label.
- Failed row in the list: plain message ("This file isn't a readable PDF.") with Try again next to it.
- Data room stats: clear KPI tiles, readable ranked bars with counts, the page scrolls inside its panel.
- Data room fits one screen at 1280x800, 1440x900 and 1920x1080 (page scroll 0, no horizontal overflow at 375); the grid uses 8 columns at 1920.
- Contacts page at desktop: calm, aligned, one primary action.
- Cap table mobile table collapse; Edit contact dialog structure and helper line.
- Activity panel: grouped by need (Needs you / Working), status in words and color, "Show 4 finished runs" caps growth.
- Skip-to-content link present; focus rings visible on every sidebar control tested; Escape returns focus after the palette.

## Audit notes

- layout-audit.js flagged low contrast (ratio 1.32) on sidebar labels. In the screenshots these are clearly legible, so I treat it as a false positive from transparent backgrounds in dark mode.
- Off-scale spacing observed on every page (6, 10, 11, 14, 18 px) and 9-11 distinct font sizes per page (10, 11, 12, 13, 14, 15, 16, 18, 20, 21, 22 px); not filed individually (norm D3, H3, P3).
- About 26 Tab stops (two per chat: row plus Actions) precede the page content; the skip link mitigates this.
