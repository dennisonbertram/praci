# Visual inspection V2 (Inbox, Finance, Legal, agent chat)

Target: mock-data demo stack (web :5381). Signed in as the demo founder. Viewports: 1440x900, 375x812, and 1920x1080 for the shell. Screenshots: `/tmp/uxloop1/V2/`. Both audit scripts (layout-audit, geometry-audit) were run on every captured state. The contrast numbers in layout-audit (about 1.3:1 on sidebar labels) came out the same on every page and look like a transparent-background artifact in the script. They are not reported as findings.

Not reached: Inbox Digest view (the Newsletters pile is empty in this data, see V2-03), real attachment preview (the only attachment is a 12 MB video, so only "Too large to preview" was seen), mobile row actions, approving or denying the Mercury card (deliberately not clicked), Finance Crypto and Spend sub-pages at 375.

## Excellent as is

- Skip link works: first Tab shows "Skip to content", Enter then Tab lands in "Search mail". Focus rings are visible (2px solid or 3px ring) on sidebar items and rows.
- Inbox thread dialog: clear title, sender, date, five labelled actions, readable body; on mobile it becomes a full-screen sheet with the same actions.
- Inbox row hover: actions replace the summary text and the unread dot becomes a checkbox without any layout shift (L5).
- Inbox on mobile: "To do" caps at two items plus "3 more", rows stay 56px, no horizontal scroll at 375 (pageOverflowX 0 on every page checked).
- Finance overview and sub-pages: summary cards, the Week/Month/Quarter/Year switch, charts and the "Updated just now" / source chips are well ordered and readable; every row is a link with a chevron. The 375 layout reflows to a clean two-column card grid.
- Runway page: the "what counts" explanation table answers the founder's next question without extra clicks.
- Chat: grouped bubbles, one composer pinned at the bottom, current chat highlighted in the sidebar, approval buttons clearly ranked (Allow once primary, Deny secondary), artifact links inline and working (link opened the right artifact in a two-pane viewer).
- Legal Deadlines tab: status chip ("Overdue by 5 days" in red), date on the right, Done and Dismiss on the row.
