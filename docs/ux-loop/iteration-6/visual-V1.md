# Visual critique V1 (iteration 6): auth, onboarding, tour, shell, Settings, Integrations, bot settings, email agent panel

Target: mock-data demo stack only (web 127.0.0.1:5381). Sessions: uxl6-V1 (fresh invented user "Maya Vee", signed up on the demo, used for sign-up, onboarding, tour, Settings, Integrations), uxl6-V1s (seeded demo founder, password passed from the credentials file straight into `fill`, never printed). Screenshots: /tmp/uxloop6/V1/. Method: layout-audit.js and geometry-audit.js at 1440x900, 1920x1080, 1280x800, 1024x768, 768x1024, 375x812 and 320x640; screenshots read by eye; axe audit; Tab and arrow order, menus, dialogs, Escape and focus return exercised. Touch findings were measured with CDP touch emulation (pointer: coarse, hover: none, 5 touch points); fine-pointer measurements are not used for touch claims.

Not tried: real OAuth Connect buttons (BLOCKED, they leave for Google or Slack), the onboarding "model" step (a fresh demo user already has OpenRouter, so it never appears), the email agent panel's "Reply with draft" button (UNVERIFIED: it only appears after the agent writes a pending mail_send card, and the mock model answered with plain text), the tour "Ask Chief" prefill collision (suspected, see V1-09). The seeded account is shared with other walkers, so its chat and sidebar changed while I worked (new bots "New Bot" and others appeared).

## Excellent as is

- Landing, sign in, sign up: one primary action, labels above inputs, helper text only where useful, no target under 44px under touch at 375.
- Onboarding: one question card with A to D choices, the answer collapsing to a single checked row, and inline Gmail and Slack Connect cards in the chat. No modal, no wizard.
- First-run tour: nine stops, honest copy (step 7 matches Settings), the last step now ends with "Done" (iteration 5 V1-05 fixed); the mobile sheet moves to the top when the target is at the bottom.
- Menus: Create menu focuses the menu, Escape closes it and returns focus to Create (iteration 5 V1-01 fixed); Pages menu has no ghost Devin row (V1-02 fixed) and no longer hides the page labels; user menu Escape returns focus to the avatar button. The Cmd+K palette that the sidebar Search opens is clean, with a Move/Open hint.
- Sidebar keyboard model: pages and chats are one roving tab stop with arrow keys, so Tab reaches the page quickly (deliberate, see roster-tab-stops.ts).
- Settings: fixed height, Escape returns focus, mobile select, General now fits; the Sidebar density control is a clear addition. Label rows for switches are now 44px tall under touch (iteration 5 V1-03 mostly fixed).
- Bot settings: Audience (Internal/External) shows an "External" chip in the chat header and a plain sentence ("Talks to people outside your company. Private tools are turned off."), the saved state says "Saved", and the panel fits one screen.
- Email agent panel: clear header, thread chip, Escape from the nested Reply composer returns to the email and the panel.
- Light theme and all breakpoints (320 to 1920): no horizontal scroll, no page scroll on app surfaces.
- Contrast in dark theme: every text colour on the shell measured at or above 4.5:1.
