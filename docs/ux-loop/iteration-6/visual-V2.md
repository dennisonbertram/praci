# Visual critique V2 (iteration 6): Inbox, Finance, Legal, agent chat

Target: mock-data demo stack only (web 127.0.0.1:5381), seeded founder Maya Chen (Mock), dark theme, session uxl6-V2. Screenshots are in `/tmp/uxloop6/V2/`.
Method: `layout-audit.js` and `geometry-audit.js` on every captured state (JSON next to each PNG), every screenshot read by eye, then hover, Tab order, menus, dialogs, Escape and focus return exercised. Norm ids are from `visual-heuristics.md`.

Pages and states covered
- Inbox: list, "Let Praci sort your mail" banner, sorting and "taking longer" states, To do and Needs reply piles, Updates, Newsletters, Digest, Cleanup (empty), Filter menu, thread, thread with attachment, attachment preview, thread More menu, email agent panel (Ask agent), the email agent's own chat, Gmail-needs-reconnect space.
- Finance: overview, Accounts, Burn, Runway, Crypto, Spend, Rent category, vendor, recurring item.
- Legal: Contracts, Deadlines, Graph.
- Agent chat: Investor Relations (question card), Finance agent (side panel, error banner), Inbox agent (mail approval card), bot settings (including Advanced), consent card.
- Viewports: 1440x900 (all), 1920x1080 (Inbox, shell), 375x812 (Inbox, drawer, thread, email agent panel, Finance, Legal, Inbox agent chat).

Limits of this run (read first)
- Touch emulation is not available in this browser tool (`set device "iPhone 16"` still gave `pointer: coarse` false and 0 touch points, and forces 393x852). Per the owner decision, no touch-target finding is reported. 375x812 was a plain narrow viewport.
- The demo stack is shared with other inspectors, so counts, sidebar chats and run states changed while I worked (for example the Inbox badge went 14 to 10). Some agent failures come from the demo model, not the UI.
- The mock model did not finish mail sorting in the first 25 s ("taking longer" state shown); the To do and Needs reply piles appeared later and were captured at 375 and 1920.
- The attachment preview iframe (blob PDF) rendered blank in this headless browser. That is most likely the headless PDF viewer, so the preview content is UNVERIFIED. Its frame, Add to Data room, Download and Escape behaviour were checked.
- A mouse click on the thread "More" button did not open its menu three times, while keyboard Enter did. I treat that as a browser-tool artifact (menu opens on pointer down) and do not report it.
- Hard loads on the dev server took 12 to 75 s (see V2-06). I waited for content before every capture.
- The Audience (Internal/External) bot setting was not found on the Inbox agent (Advanced included). Not verified on other bots.
- My "Ask agent" and click tests created extra email-agent chats in the demo sidebar (relevant to V2-02). Nothing was sent or deleted. I did not press Send on any approval card.
- agent-browser lost its browser once mid-run; I signed in again with the same demo account.

## Excellent as is
- Inbox thread dialog and attachment preview frame: clear header, Reply is the one filled button, Archive and More are secondary, Add to Data room and Download in the preview, and Escape closes preview, then thread, returning focus to the exact row.
- Mail approval card in the Inbox agent chat: From, To, Cc, body, one filled Send, plain Discard, "Needs approval" in words, now signed with the user's name.
- Inbox sort states: "Sorting is taking longer than usual. Your mail is below. [Try sorting again]" tells the truth, keeps the mail usable, and offers one retry.
- Gmail-needs-reconnect empty state: icon, plain reason, one button ("Reconnect Gmail"); fits at 1920x1080. (Real OAuth not attempted.)
- Mobile Legal: table becomes labelled cards, tabs and the red failed-scan banner reflow, no horizontal overflow.
- Finance Accounts, Burn, vendor and recurring pages: one header pattern with a labelled back button, KPI cards with basis lines, chart axes and bar labels that read at a glance, "Brex does not share it" as an honest empty value.
- Finance overview: figures agree across pages (cash $1,633,221, runway 24.2 months, crypto $105,250).
- Layout fit: no page scroll or horizontal overflow on any inspected page at 1440x900, 1920x1080 or 375x812; long content scrolls in its panel.
- Row focus in the Inbox: visible focus ring, the checkbox replaces the unread dot without shifting layout, and the action icons appear on focus.
- Consent card copy now reads "GPT-6 Luna (via OpenRouter)" and shows an "Allowed" state.
