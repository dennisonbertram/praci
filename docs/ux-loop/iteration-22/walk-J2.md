## What was excellent

- Mercury "Allow changes" dialog now says "move money and change your Mercury accounts"; the earlier vague wording is fixed.
- The payment approval card is one plain sentence ("Send $1,200.00 to ... from MOCK Checking ..1111?") with a button that repeats the amount, a Details toggle with amount, recipient, account and note, and Deny. After approval it says "Approved here. Waiting for Mercury" and the agent explains the Mercury-side approval. After Deny a new card appears only on a new request.
- Bulk selection in the Data room offers Download, Email and Send to agent; Email opens a composer with the files attached. This closes the "no packet" gap recorded in STORY-APP-214.
- Data room file that is not a readable PDF shows "Couldn't read this file" with Replace file and Delete, and the Data room agent states which contracts it could not verify.
- Routine form defaults are sensible (Every week, Monday 9:00 AM), the saved routine shows "Next run Mon, Oct 26, 9:00 AM", Test run records a run history row ("Waiting on Inbox agent") with a View chat link.
- Skill form is inline in bot settings; the saved skill shows in the `/` picker immediately.
- Legal deadlines: Done shows an Undo row and the sidebar badge updates; the Legal agent drafts without sending and says so.
