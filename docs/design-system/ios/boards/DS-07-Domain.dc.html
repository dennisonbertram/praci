Avatars and domain components

Content-layer components for bots, people, Finance, Legal, Cap table, Data room, Artifacts, Integrations, Computer and Calls. Only the keyboard bar floats as glass. Dark specimens at real iPhone size; amounts are placeholders.

BotAvatar

Purpose. Identity of an agent. Each bot has its own real Praci shape, so no two bots look alike; color is the only identity color in the app.
Anatomy. One of 8 shapes (hex, wedge, squircle, tablet, pebble, blob, teardrop, cloud) filled with the bot color, and two ink eye pills (#1C1C1A), with an optional state ring and corner badge. Drawn from one SVG path per shape in a 259 x 259 box.
Shape rule. Shape = hash of the bot id over SHIPPED_BOT_AVATAR_SHAPE_KEYS (packages/core/src/bot-avatar-shapes.ts), unless the bot sets one explicitly. Color = the bot color. Never two bots with the same shape and color on one screen.
Fixed mapping in these boards. Chief hex #3EC5A8, Inbox agent tablet #3B82F6, Finance agent wedge #F5A03C, Legal agent teardrop #9B5CF6, Projects squircle #6A6BF5, Team pebble #F2622A, further bots blob #D9508A then cloud. Integration agents (Carta, Mercury, Brex) keep the letter tile.
Sizes. 22 (inline mention), 28 (row in dense list), 40 (list row, header), 64 (agent profile, call). The ring sits 4-5pt outside the box.
States. idle (eyes blink, slow look-around), working (blue #4F8FF7 ring spins, 1.2s linear), done (smile eyes, success ring + check badge), error (X eyes, destructive ring + x badge). Badge shown at 40pt and up; below that the ring carries the state.
Layer. Content. Never glass.
Praci source. apps/mobile/components/bot-avatar.tsx, packages/ui-web/src/bot-avatar.tsx (mood from run status).
Do. Pair every non-idle ring with the row status text for VoiceOver ("working"). Keep eyes ink on all bot colors (contrast above 4.5:1).
Don't. Do not tint or add glass behind the avatar, do not reuse one shape for two bots on a screen, and do not use a bot color for anything but identity.

GroupAvatar, user initials, integration letter tile, AppMark

Purpose. Identify a group thread, a person, an integration agent, and the Praci product itself.
GroupAvatar. 2 members: two marks at 65% of size, offset diagonally. 3+: three marks at 54% in a triangle, 2pt #1C1C1A cut-out between marks. One member falls back to BotAvatar.
Initials. Circle, #33322F fill (chatUser), 1-2 letters, 38% of size, weight 600.
Letter tile. Integration agents have no third-party logo. Rounded 10pt tile, #2A2927 fill, 1px #2E2D2A border, first letter of the name, 45% of size.
AppMark. Praci product mark: ink rounded square (#F1F0EB) with the two-eye face in #1C1C1A. 28pt in headers, 64pt on empty states.
Layer. Content.
Praci source. apps/mobile/components/group-avatar.tsx, connector-icon.tsx (letter fallback); web: docs/design-system/components.md, ai and integrations groups.
Don't. Do not draw partner logos; do not use bot colors on user initials.

Finance

Purpose. Read-only money summary from Mercury / Brex. All amounts are placeholders.
Stat tile. Card #252523, radius 16, padding 14x16. Label 12 muted, value 26/600 tabular, sub 12 muted. Two per row on iPhone, four on inner display.
Spend bar chart. Bars #33322F, radius 6, one highlighted bar in primary (#F1F0EB) for the selected month; month labels 11pt muted. Heights are placeholder data. Selection announces "Aug, [AMOUNT]" to VoiceOver.
Transaction row. 56pt min height. Letter tile, merchant, date and account, amount right-aligned tabular. Inflow uses success green; outflow stays ink.
Hidden amounts. Privacy toggle (eye.slash) replaces every amount with three dots. Layout does not shift.
SF Symbols. eye / eye.slash, chevron.right.
Layer. Content.
Praci source. docs/design-system/components.md, Web components / finance (stat tiles, spend chart, transaction list).
Don't. Do not color outflow red; red is for failures.

Artifacts

Artifact row. 56pt min height. Type icon tile, title, producing agent and date, type chip, chevron. Opens the viewer.
Preview cards. 300pt wide card, radius 16, 140pt preview area on #1C1C1A, title and type chip below. Markdown renders text lines, image shows the image (aspect fill), HTML shows a sandboxed render with no scripts and no network.
Chips. Type chip (Markdown, Image, HTML) and a "Sandboxed" chip with lock for HTML; muted capsule, 24pt tall.
States. Loading: preview area shimmer. Failed to render: warning icon + "Can't preview" text, row still opens.
SF Symbols. doc.text, photo, chevron.left.forwardslash.chevron.right, lock, chevron.right.
Layer. Content. Viewer toolbar floats as glass above it (see Glass sheet).

Computer

ComputerCard. Card in a thread/agent page: 150pt live thumbnail (frame refresh about 1/s), Live indicator, title, status with step x of y (tabular), Open computer button. Idle shows last frame dimmed.
Mode picker. Segmented control, Team / Private, 38pt segments in a 44pt capsule. Native UISegmentedControl on device.
Update progress. Card with title ("Updating Team Computer"), current phase (Getting ready, Saving your workspace, Recreating the computer, Restoring your workspace, Reconnecting), 4pt bar. Failed: destructive phase text "Update failed" + Try again.
Keyboard bar. Row of 44pt keys above the system keyboard: Esc, Tab, arrows, Ctrl. Each key has an accessibility label. Shows when the computer view is focused; it is an input accessory and may use system glass on device.
SF Symbols. display, keyboard, arrow.clockwise, chevron.right.
Layer. Content, except the keyboard bar (floating control).
Praci source. apps/mobile/components/ComputerCard.tsx, computer-mode-picker.tsx, computer-update-progress.tsx, computer-keyboard-bar.tsx.

Call and voice chat

CallCard. Card in the thread while a call is live. Bot avatar (working ring while the agent speaks), name, status and timer (tabular), 16-bar waveform (3pt bars, ink), and four 56pt round controls: Settings, Transcript, Mute, Hang up.
Controls. Round, 56pt, #2A2927; Mute turns prominent ink when muted (waveform dims to 40%). Hang up is the one red round button (#F46262 fill, ink glyph). Labels are accessibility labels.
VoiceChatCard. Compact summary after or during a voice chat: title "Voice chat", duration, and a disclosure to show or hide the transcript.
SF Symbols. mic / mic.slash, phone.down.fill, text.bubble, slider.horizontal.3, chevron.down.
Layer. Content. On the full-screen call view the control row floats as glass; here the controls sit in the card.
Praci source. apps/mobile/components/CallCard.tsx, VoiceChatCard.tsx.
Don't. Do not add a second red button; Hang up is the only destructive control.
