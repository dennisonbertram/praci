Outer display page rules
How to generate any page for the 466x678 outer display, then one rule card per core page. Inner and laptop poses are derived from the same recipe.
How to generate any page
1
Name the job. Write one sentence: what the person does here and what the single most likely next action is. That action becomes the one prominent control.
2
List the data and its states. Primary data, plus empty, loading, error and (if it applies) working or needs-approval states. Every page must draw all of them from the same layout.
3
Pick components from the DS sheet. Navigation, Lists, Chat, Overlays, Controls, Domain. Reuse a named component before drawing anything new.
4
Split into two layers. Content layer: text, rows, cards, bubbles, documents (card or muted fills, never glass). Control layer: side bar, title capsule, composer, pills, menus (glass).
5
Build the outer side strip (466x678). Left 62pt strip, top to bottom: Dynamic Island, time, Back or Close group, then one action group (max 3 icon-only buttons), spacer, More group, then the prominent button last. At most 3 glass groups plus the prominent one.
6
Build the content column. Starts at x=72. Large title (28pt) for list pages, or a glass title capsule at the top of the column for object pages. Content scrolls under the capsule and composer; reserve 66pt at the bottom when a composer floats.
7
Place floating elements. Composer, add-item field, version pill and key bar float 12pt above the bottom edge as one regular-glass capsule. Never stack a second glass layer on it.
8
Decide glass vs clear. Regular glass over text content. Clear glass (35% dark dim) only over live media: Team Computer and Image. Prominent = ink fill, one per view.
9
Derive the inner book layout (890x626, flat). 1/3 sidebar column with the parent list or the page tree, 2/3 detail. The extra level is the parent collection (for a thread: the list of agents; for a message: the inbox). The one inner sidebar (Personal, Activity, Pages, Agents, profile row) is the third; the side bar moves to the right edge. Half-folded: snap to 1/2 + 1/2 with nothing important at x 435-455. Pick a template: List + detail, Live view + controls, or Form.
10
Derive the laptop pose (626x890). Only for pages with a live view or a composer: view in the top half, controls (composer, key bar, actions) in the bottom half as horizontal bars. Static reading pages mark it not applicable and stay full-height. Pick a template: List + detail, Live view + controls, or Form.
11
Check parity. Every action in the outer side strip exists on inner and laptop with the same label and SF Symbol. Same state, same copy, one extra hierarchy level on inner only.
12
Write the copy last. Treat each visible word as UI. Remove any label an icon, title or position already says; use [AMOUNT] and [N] placeholders for figures.
13
Derive the standard iPhone (393x852). The outer-display content column with a top bar instead of the side strip; sheets keep the medium and large detents; the one prominent action keeps its place.
What survives a posture change. The draft, scroll position, selection, open thread, running stream and Computer session all survive folding and unfolding. Back returns to the page you came from.
Ask [page] agent. It opens the thread in the right half (half-folded) or replaces the detail pane with Back to [page] (inner flat).
Duo is the layout target. Artifacts, Image, Agent page, Routine and form sheets are designed for the Duo displays first; the standard iPhone derives from them (a top bar instead of the side strip, sheets keep the medium and large detents).
Rule cards (12 pages)
Home
ROUTE AND PURPOSE
index.tsx (Home). Entry point: see who needs you, open an agent.
PRIMARY DATA
Inbox summary (counts), activity items (working, needs approval, routine ran), Agents and apps.
COMPONENTS (DS SHEET)
Lists (inbox row, activity group, agent row), Domain (agent avatar, app tile), Navigation (side strip), Controls (prominent New).
OUTER LAYOUT RECIPE
Side bar: Island, time, Account group, Search / Activity group (Activity carries a dot when something needs you), spacer, prominent New. Content: Space title Personal with a menu, then the sections in one fixed order on every Home surface (outer, inner, standard iPhone): Activity, Inbox, AGENTS (Chief first), Pages, then Artifacts, with a bottom fade. Home AGENTS shows the four most recent rows, then a Show N more row; unread rows are never hidden; no Show row appears with four or fewer.
INNER BOOK 1/3 + 2/3
Sidebar third: the one inner sidebar (Personal title with a menu and New, Activity, Pages with glance values, Agents, a profile row that opens Settings). Detail two thirds: the open page, Inbox by default. Drawn: Split.
HALF-FOLDED 1/2 + 1/2
Left half: the open page with Back to Personal. Right half: its agent thread with the composer. Drawn: Inner.
LAPTOP POSE
Not applicable (a launcher has no live view). Stays one column.
EMPTY, LOADING, ERROR
Empty: "No agents yet" with New agent. Loading: three placeholder rows. Error: "Could not load agents" plus "Try again." Activity hides when nothing is running.
GLASS VS CONTENT
Glass: side strip only. Content: inbox card, activity card, rows. Activity icon dot is the only badge.
ACCESSIBLE NAMES
Space: Personal (menu), Account, Search, Activity (reads "Activity, 1 needs you"), New.
THE ONE PROMINENT ACTION
New (plus, SF: plus). Menu: New agent, New group, New space.
Inbox
ROUTE AND PURPOSE
inbox.tsx. Triage mail; open one message.
PRIMARY DATA
Mail threads in sections (Needs reply, Today, Earlier) with unread dot, sender, subject, snippet, label. Inbox is one page with those three sections.
COMPONENTS (DS SHEET)
Lists (mail row, section header), Domain (label dot), Navigation (side strip).
OUTER LAYOUT RECIPE
Side bar: Back, group Search mail / Filter / Compose, spacer, More (the ... menu; Cleanup is reached only from here), then prominent Ask Inbox agent (SF: bubble.left) last. Content: 28pt title, sections of divided rows with no cards. Needs reply rows are bold; newsletters are regular.
INNER BOOK 1/3 + 2/3
Sidebar third: the one inner sidebar with Inbox selected. Detail: message list; the extra level is the open message beside it. Search mail sits in the list header. Drawn: Split.
HALF-FOLDED 1/2 + 1/2
Left: list with Back to Personal. Right: selected message or Inbox agent thread. Drawn: Inner (thread) and Inner-Message (message).
LAPTOP POSE
Not applicable.
EMPTY, LOADING, ERROR
Every drawn state: list, swipe actions (Archive, Spam), Archived with Undo, Archive failed (row stays), Gmail needs reconnecting (Reconnect), No mail account (Connect Gmail), Consent needed (Allow, Not now), First sync (Syncing your mail). Empty: "Inbox zero" line with the last sync time. Loading: placeholder rows. Error: "Could not load mail." with "Retry." Cleanup: pick senders, then Archive and Unsubscribe each get their own confirm; Archive can be undone, Unsubscribe cannot.
GLASS VS CONTENT
Glass: strip. Content: rows. Unread is a filled dot plus semibold; no tinted rows.
ACCESSIBLE NAMES
Back, Search mail, Filter, Compose, More, Ask Inbox agent.
THE ONE PROMINENT ACTION
Ask Inbox agent.
Inbox message
ROUTE AND PURPOSE
inbox-message.tsx. Read one email and decide: archive, reply, or ask the agent.
PRIMARY DATA
Subject, sender, recipient, date, body (text or sandboxed HTML), attachments.
COMPONENTS (DS SHEET)
Lists (attachment row), Chat (none), Domain (sender avatar), Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, group Archive (SF: archivebox) / Reply (SF: arrowshape.turn.up.left), spacer, prominent Ask Inbox agent (SF: bubble.left). Content: 22pt subject, sender line, body at 15pt, attachment rows.
INNER BOOK 1/3 + 2/3
Sidebar third: the inbox list with this message selected. Detail: the message. Extra level: the list stays visible. Inbox is one page with Needs reply, Today and Earlier sections. Inner: Reply opens the composer under the message; after Archive the next row opens; with nothing left the list shows Inbox zero; Cleanup stays in the list More menu.
HALF-FOLDED 1/2 + 1/2
Left: list. Right: message; Reply opens the composer under it. Drawn: Inner-Message. Archive selects the next row down.
LAPTOP POSE
Not applicable.
EMPTY, LOADING, ERROR
Loading: spinner in the body area. Error: "Could not load mail." centered, with "Retry." Sent mail shows a Sent check beside the date. Attachment over size: row shows size and a disabled state.
GLASS VS CONTENT
Glass: strip only. The body is content on the page background; the HTML preview is sandboxed and never glass.
ACCESSIBLE NAMES
Back, Archive, Reply, Ask Inbox agent.
THE ONE PROMINENT ACTION
Ask Inbox agent. Reply is an ordinary glass button.
Agent thread
ROUTE AND PURPOSE
thread.tsx. Talk to one agent and approve its actions.
PRIMARY DATA
Messages, tool-call labels, working status, approval cards, composer text.
COMPONENTS (DS SHEET)
Chat (bubble, tool label, working indicator, approval card, composer), Overlays (agent actions menu), Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, group Page (SF: doc.text) / List (SF: checklist), spacer, More group (agent actions: settings, open computer, clear, archive, delete). Content column: glass title capsule at the top, messages bottom-aligned, floating composer at the bottom. No prominent in the strip; Allow in the approval card is the one prominent control. Always allow appears only for read-only tools; sending, paying or deleting asks every time. Long press a message: a row of emoji reactions plus Reply and Copy.
INNER BOOK 1/3 + 2/3
Sidebar third: the one inner sidebar. Detail: the thread. Page and List open as a further third pane when asked.
HALF-FOLDED 1/2 + 1/2
Left: the page the agent belongs to (the Inbox list for the Inbox agent) with Back to Personal. Right: thread with composer and its draft. Drawn: Inner.
LAPTOP POSE
Top half: thread. Bottom half: composer and quick actions as a horizontal bar. Approval card sits above the composer.
EMPTY, LOADING, ERROR
Empty: agent greeting and suggestions. Loading earlier messages: small spinner at the top. Error: inline "Failed to send message" with Retry. Oversize file: "File is over the 25 MB limit" with Remove file. Working: avatar, ring and neutral dots pill (DS-06), no text, hidden while a card awaits approval; Stop in the composer slot.
GLASS VS CONTENT
Glass: title capsule, composer, strip. Content: bubbles, tool label, approval card (card fill). Do not make bubbles glass.
ACCESSIBLE NAMES
Back, Page, List, More; composer: Attach (+), message field, Dictate or Send, Stop while working; approval card: Edit, Send.
THE ONE PROMINENT ACTION
Send on the approval card while pending; otherwise composer Send or Stop.
Group thread
ROUTE AND PURPOSE
group-thread.tsx (re-exports thread.tsx in group mode). Talk to several agents at once.
PRIMARY DATA
Messages from several agents with names, member list, per-agent working status.
COMPONENTS (DS SHEET)
Chat (named bubble, working indicator, composer), Domain (stacked member avatars), Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, group Members (SF: person.2) / Page, spacer, More (group settings). Content: glass title capsule with stacked avatars, agent name above each bubble, floating composer. Long press a message: a row of emoji reactions plus Reply and Copy.
INNER BOOK 1/3 + 2/3
Sidebar third: the one inner sidebar. Detail: the group thread. Extra level: member list opens as a third pane.
HALF-FOLDED 1/2 + 1/2
Left: members and groups. Right: thread.
LAPTOP POSE
Top half: thread. Bottom half: composer. Same as Agent thread.
EMPTY, LOADING, ERROR
Empty: member avatars and "Message the group". Working: one avatar and dots pill per working agent. Error: as Agent thread. One member removed: its bubbles keep the name.
GLASS VS CONTENT
Glass: capsule, composer, strip. Content: bubbles. Agent identity is the avatar color only.
ACCESSIBLE NAMES
Back, Page, Members, More; composer: Attach (+), message field, Send or Stop.
THE ONE PROMINENT ACTION
Send (composer).
Agent page
ROUTE AND PURPOSE
agent-page.tsx. Read the document an agent keeps pinned.
PRIMARY DATA
Page blocks: markdown, charts (SVG), key figures.
COMPONENTS (DS SHEET)
Domain (figure tiles, chart), Navigation, Controls.
OUTER LAYOUT RECIPE
Side bar: Back, group List (SF: checklist), spacer, prominent Open chat (SF: bubble.left). Content: glass title capsule with agent name, then a document with 24pt title, figure tiles, chart, text.
INNER BOOK 1/3 + 2/3
Sidebar third: the agent thread. Detail: the page. Extra level: thread and page side by side.
HALF-FOLDED 1/2 + 1/2
Left: page. Right: thread or list.
LAPTOP POSE
Full height; no split.
EMPTY, LOADING, ERROR
Empty: "No page yet." Loading: spinner. Error: "Could not load this page." with Retry; keeps an already loaded page. Chart failure: "Chart could not be drawn." in place.
GLASS VS CONTENT
Glass: capsule, strip. Content: the document and chart on card fill.
ACCESSIBLE NAMES
Back, List, Open chat.
THE ONE PROMINENT ACTION
Open chat.
Agent list
ROUTE AND PURPOSE
agent-list.tsx. Work through an agent checklist; add items.
PRIMARY DATA
List title, items (done or open), draft text for a new item.
COMPONENTS (DS SHEET)
Lists (checklist row, Add item row), Controls (checkbox), Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, group Page, More, spacer, prominent Open chat (SF: bubble.left). Content: agent title capsule, list title with "N of M done", open items, an Add item row inline below them (tap to type; the keyboard Add key saves), then a Done section.
INNER BOOK 1/3 + 2/3
Sidebar third: Page and chat of the same agent. Detail: the list.
HALF-FOLDED 1/2 + 1/2
Left: list. Right: thread.
LAPTOP POSE
Full height; no split.
EMPTY, LOADING, ERROR
Empty: the Add item row only. Error: "Couldn’t load this list" with Retry. Save failure: "Could not save this list." with one Retry and the row reverts. More menu: Clear done items, Copy as text.
GLASS VS CONTENT
Glass: capsule, strip. Content: rows with a divider, including the Add item row; done items are muted and struck through.
ACCESSIBLE NAMES
Back, Page, More, Open chat; each row reads "Mark done" or "Mark not done" and its text; Add item.
THE ONE PROMINENT ACTION
Open chat.
Computer
ROUTE AND PURPOSE
computer.tsx. Watch and, when needed, drive the agent's Team Computer.
PRIMARY DATA
Live screen, control state, mode (Team or Private), keyboard keys.
COMPONENTS (DS SHEET)
Controls (mode picker, key bar), Overlays (control chip), Navigation.
OUTER LAYOUT RECIPE
Side bar (clear glass): Close, group Keyboard (SF: keyboard) / Fit to screen, spacer, prominent Take control (SF: cursorarrow) when watching; the same slot holds Release (SF: lock.open) when in control, labelled "Release control", or "I'm done" while an agent waits for you. No Close while in control. Over the screen: clear Team/Private picker top-left, control chip top-right, clear key bar at the bottom while in control.
INNER BOOK 1/3 + 2/3
Sidebar third: the one inner sidebar. Detail: the screen with the agent thread beside it (so you can talk while watching).
HALF-FOLDED 1/2 + 1/2
Left: thread. Right: screen. Fold stays clear of the screen.
LAPTOP POSE
Top half: the screen. Bottom half: Keyboard and Fit group, Release in the Take control slot, key bar above the system keyboard; with the keyboard closed, the thread composer. Drawn: Desk-Computer.
EMPTY, LOADING, ERROR
Booting: "Booting [name]" with a progress bar. Starting: "Starting Team computer" with Take control at the bottom. Error: "Could not open computer" with Retry. Screen cannot load: "Could not load the desktop." Handoff asks: Skip / I'm done.
GLASS VS CONTENT
Clear glass only, over media, with a 35% dark dim top and bottom. The screen is content and never glass.
ACCESSIBLE NAMES
Close computer, Keyboard, Fit to screen, Scope (Team, read-only), Take control, Release control; keys Escape, Tab, Control, arrows.
THE ONE PROMINENT ACTION
Take control, then Release.
Routine
ROUTE AND PURPOSE
routine.tsx. Check one scheduled routine and jump to its conversation.
PRIMARY DATA
Name, schedule, last run, next run, prompt.
COMPONENTS (DS SHEET)
Lists (status card, prompt card), Controls, Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, More (Pause routine, Edit routine), spacer, prominent Open chat (SF: bubble.left). Content: agent title capsule, routine name, status card with Open last run and Run now as content buttons (Run again after a failure, Resume while paused), then the PROMPT label and card. The Routines list has Back and a prominent New routine (plus).
INNER BOOK 1/3 + 2/3
Sidebar third: the agent's routines list with this one selected. Detail: the routine.
HALF-FOLDED 1/2 + 1/2
Left: routines. Right: detail.
LAPTOP POSE
Not applicable.
EMPTY, LOADING, ERROR
Loading: spinner. Error: "Could not load routine" with Retry. Deleted: "This routine no longer exists". Bad link: "Routine link is incomplete".
GLASS VS CONTENT
Glass: capsule, strip. Content: status and prompt cards.
ACCESSIBLE NAMES
Back, More, Open chat, Open last run, Run now.
THE ONE PROMINENT ACTION
Open chat on a routine; New routine on the Routines list.
Artifacts
ROUTE AND PURPOSE
artifacts.tsx. Browse files and documents agents made.
PRIMARY DATA
Artifacts with name, type, agent, version, date; agent filter.
COMPONENTS (DS SHEET)
Lists (artifact row), Controls (filter chips), Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, group Search artifacts (SF: magnifyingglass), spacer. No prominent; the rows are the action. Content: 28pt title, chip row (All agents first, active chip is ink), divided rows with a type tile.
INNER BOOK 1/3 + 2/3
Sidebar third: agent filter as a vertical list (replaces chips). Detail: artifact rows. Extra level: preview of the selected row.
HALF-FOLDED 1/2 + 1/2
Left: list. Right: preview.
LAPTOP POSE
Not applicable.
EMPTY, LOADING, ERROR
Empty: "No artifacts yet". No search results: "No matching artifacts". Error: "Could not load artifacts." plus "Try again." Long press a row: delete confirm.
GLASS VS CONTENT
Glass: strip only. Chips and rows are content.
ACCESSIBLE NAMES
Back, Search artifacts; each chip and row reads its text.
THE ONE PROMINENT ACTION
None. Opening a row is the action.
Artifact
ROUTE AND PURPOSE
artifact.tsx. Preview one artifact, open older versions, share.
PRIMARY DATA
Artifact name, version list, rendered HTML, markdown or image.
COMPONENTS (DS SHEET)
Lists (preview card), Overlays (More menu, Versions menu), Navigation.
OUTER LAYOUT RECIPE
Side bar: Back, More (Versions, Open page), spacer, prominent Share (SF: square.and.arrow.up). There is no Share/Versions group. Content: title with an "Updated ... Version N" line, then the preview card. A Version pill with Restore appears at the bottom only while an older version is open.
INNER BOOK 1/3 + 2/3
Sidebar third: artifacts list. Detail: preview. Extra level: the list stays visible.
HALF-FOLDED 1/2 + 1/2
Left: list. Right: preview.
LAPTOP POSE
Full height; no split.
EMPTY, LOADING, ERROR
Loading: "Loading…" title and spinner. Error: "Could not load this artifact." Unsupported: "No preview for this file type."
GLASS VS CONTENT
Glass: strip, and the Version pill while an older version is open. Content: preview card. HTML preview is sandboxed.
ACCESSIBLE NAMES
Back, More, Share; in Versions each row reads its version and date; Restore.
THE ONE PROMINENT ACTION
Share.
Image
ROUTE AND PURPOSE
image.tsx. Look at one image full screen.
PRIMARY DATA
Image, file name, type.
COMPONENTS (DS SHEET)
Controls (clear buttons), Navigation.
OUTER LAYOUT RECIPE
Side bar (clear glass over the media): Close, group Share / Save to Photos, spacer, More. Image fills the whole artboard; a 35% dim lies under the controls; a clear name pill floats at the bottom.
INNER BOOK 1/3 + 2/3
Detail only: image fills two thirds, thread stays as the sidebar third.
HALF-FOLDED 1/2 + 1/2
Image on one half, thread on the other.
LAPTOP POSE
Image on the top half, controls on the bottom half; rotates freely.
EMPTY, LOADING, ERROR
Loading: spinner on black. Error: "Could not load this image." with Close still available.
GLASS VS CONTENT
Clear glass only (media). Nothing else is glass.
ACCESSIBLE NAMES
Close, Share, Save to Photos, More.
THE ONE PROMINENT ACTION
None; Close is the main control.
