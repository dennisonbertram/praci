Composer

GLASS

Purpose. Floating input above the thread. Replaces thread-composer.tsx, composer-reply-preview.tsx, reply-dismiss-button.ios.tsx.

Anatomy: 44pt glass circle Attach (plus, 8pt gap) then a glass capsule: radius 26, min height 52, 16pt leading padding, 4pt trailing inset so the 44pt trailing control is concentric (26 - 4 = 22). Text 16pt; grows to 6 lines, then scrolls. Chip row (32pt chips) sits inside the capsule above the text.

Trailing control: empty = Dictate (mic, bare, no extra glass inside the capsule); text present = Send (arrow.up) as the single prominent tinted button, fill rgba(241,240,235,0.92), ink arrow; agent running = Stop (stop.fill) in the same prominent slot. Send is disabled with no text and no attachment.

Reply preview: glass strip above the capsule, radius 20, bar + name + snippet + optional thumbnail + dismiss (xmark.circle.fill, 24pt visual in 44pt target; native button on iOS).

Mention popover: typing @ opens a glass list above, radius 22, rows 44pt with MentionOptionIcon (28pt bot letter tile, or person.fill circle for teammates), name, role; first row selected. Dismiss on Escape, tap away, or deleting the @.

Do not stack the popover and reply preview; the popover replaces the preview position while open. Keep one prominent button. Composer rises with the keyboard and the home indicator inset.

CONTENT

Purpose. The agent pauses for a decision. Replaces McpApprovalCard.tsx, AskActions.tsx, ChoiceCard.tsx and AskBlock in thread.tsx (web: AskCard.tsx).

MCP approval: letter tile (integration agents, no logos), title, tool name in mono, arguments summary in an inset well (#1C1C1A, radius 14, 13pt, max 4 lines; amounts are tabular). Actions stacked, full width, 44pt: Allow once (prominent), Always allow (solid secondary fill), Deny (solid secondary fill, destructive text). Labels come from the ask: allow, always, deny.

Voice player bar

GLASS

Purpose. Plays a voice message or read-aloud reply, floating above the thread. Replaces voice-player-bar.tsx.

Anatomy: glass capsule, radius 28, min height 56. Play/Pause (play.fill / pause.fill) is the one prominent tinted circle (44pt). 20 waveform bars (3pt wide, played = foreground, unplayed 35%), elapsed / total in tabular 12pt, speed (1x, 1.5x, 2x; cycles), Close (xmark, 44pt).

States: paused, playing, loading (play shows spinner, bars flat at 8pt), error (bars replaced by Could not play and a Try again text button). Scrubbing: drag the waveform; VoiceOver adjustable.

Do dock it above the composer, never inside the capsule (no glass on glass). Do not show it when nothing plays.
