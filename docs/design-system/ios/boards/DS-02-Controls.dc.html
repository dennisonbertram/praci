Controls
Buttons, icon buttons, switch, segmented control, checkmarks, menu, slider, stepper, chips, fields and the hide-amounts toggle. Glass is the control layer; list rows and chips stay in the content layer. Dark first, light where it differs.

Button

Purpose. Text and icon actions. Source component: NativeActionButton (SwiftUI Button in a Host).

Styles. glass (secondary, regular glass capsule), glassProminent (one per view: ink fill #F1F0EB, ink label), plain (borderless, foreground), quiet (plain, mutedForeground, small), destructive (role destructive: red label on glass; glassProminent tinted #F46262 with ink label for confirm steps only).

Sizes. small 36pt, regular 44pt, large 52pt. Capsule radius. Side padding 14 / 20 / 26. Label 14 / 17 / 17, weight 500. Small gets a 4pt hit slop to reach 44. Full-width large stretches (fill), min height 48.

Content. Label, icon + label (icon 17pt, 7pt gap), icon only (use Icon button below). Icon-only needs an accessibility label.

States. default, pressed (scale 0.96, brighter fill), focus (2pt #3B82F6 ring, 3pt offset), disabled (40% opacity), loading (circular spinner replaces the icon; label may change to a progress verb; control inactive).

SF Symbols. archivebox, paperplane, trash, square.and.pencil, chevron.right.

Do. Make the preferred choice prominent by style, not size. Keep prominent to one or two per view. Don't. Make a destructive action the primary role; stack a button on glass; draw glass inside a list row.

Icon button and groups

Purpose. Toolbar and overlay actions. Source component: GlassIconButton (apps/mobile/components/glass-icon-button.tsx): a circular GlassSurface wrapping a Pressable.

Single. 40pt circle (default), 17pt symbol, 4pt hit slop (48pt target). Icon is foreground on glass; pressed drops to 60% opacity. selected fills with the primary token and inks the symbol. tint tints the glass.

Grouped capsule. Related actions share one glass capsule, 44pt tall, items 44pt wide, no dividers, symbol 20pt. Pressed item gets a 12% white inner capsule (inset by the group padding, so radii stay concentric). No glass on glass: items inside a capsule are flat. Max three groups per bar: Back/Close alone at the leading end, actions, then More (ellipsis) last. On the Duo outer display the groups run as vertical capsules down the side strip.

States. default, pressed, selected, disabled (40%), focus ring.

SF Symbols. chevron.left, xmark, square.and.pencil, archivebox, paperplane.fill, ellipsis, eye.

Note. Grouped capsules are not in the app yet; build them as native toolbar item groups. Do give each item a label for overflow. Don't put text and icons in the same group.

Switch

Purpose. Binary setting in a list row. Source component: NativeSwitch (SwiftUI Toggle with toggleStyle("switch"), labels hidden). The visible label lives in the row; the switch carries only the accessibility label and hint. Web counterparts: packages/ui-web/src/components/ui/switch.tsx, toggle.tsx (pressed toggle button).

Anatomy. 51 x 31pt track, radius 16; 27pt knob, 2pt inset. While pressed the knob stretches to 34pt wide. Row min height 52pt, switch trailing, 16pt padding.

Color. Monochrome tint: on track is ink #F1F0EB with an ink knob; off track #4A4944 with a light knob. tintColor can override; the iOS default green is shown as a fallback. Needs a native check: whether the SwiftUI knob can be recolored. If not, use the green fallback.

States. off, on, pressed, focus, disabled (40%), busy (knob shows a spinner; control inactive while the save round-trips).

Do. Apply the change immediately. Don't use a switch for an action; use a button.

Segmented control and SegmentedPills

Purpose. Pick one of 2 to 4 short options in place (view mode, filter scope). Source components: NativeSegmentedControl (SwiftUI Picker, pickerStyle("segmented"), 32pt minimum height, full width) and SegmentedPills (fallback for Android and for an unmatched value, apps/mobile/components/segmented-pills.tsx).

Native anatomy. Capsule track 32pt tall, 2pt padding, selected segment a lighter capsule, selected label weight 600. Segments share the width equally, label 13pt. Control is in the content flow, not floating, so the track is a flat fill (#2A2927), not glass.

Pills anatomy. Track radius 10, padding 2, segment radius 8 (concentric), vertical padding 8, label 15pt. Selected fill: chatUser #33322F (dark), card (light). Track is accent.

States. default, pressed segment, selected, disabled (50%), no selection (pills fallback, nothing highlighted), focus.

Do. Keep labels to one word. Don't use more than four segments; use a menu picker.

Checkmark, checkbox and chevron

Purpose. Trailing and leading row accessories. Source: Checkmark and Chevron in apps/mobile/components/row-accessories.tsx. Web checkbox: packages/ui-web/src/components/ui/checkbox.tsx.

Checkmark. checkmark, 16pt, foreground, trailing on the selected row of a single-choice list. Unselected rows show nothing. Row is the 52pt tap target.

Chevron. chevron.right, 14pt, tertiary label color (decorative, hidden from accessibility), trailing on rows that open a screen. Points down (chevron.down) while a section is expanded. Not shown on rows that run an action or toggle.

Checkbox (multi-select). 24pt circle, 1.5pt border; checked fills primary with an ink checkmark; mixed shows a dash. Leading in selection mode (Auto-sort review, bulk archive). Row stays the 52pt target; announce as checkbox with checked state.

States. default, pressed, checked, mixed, disabled, focus.

Content layer. No glass. Don't combine a chevron and a checkmark in one row.

Menu picker

Purpose. Choose one value from 3 to 8 options without leaving the screen. Source components: MenuPicker and MenuPickerMenu (apps/mobile/components/menu-picker.tsx): a native MenuView from @expo/ui wrapping any trigger. The current choice carries the system checkmark (state: on).

Row trigger. Min height 52pt, 16pt padding; label 16pt left, current value 16pt secondary right-aligned, chevron.up.chevron.down 13pt tertiary. Whole row is the target.

Button trigger. Glass capsule, 44pt (36pt compact), value + chevron.up.chevron.down. Icon-only trigger: ellipsis in a glass circle (More).

Open menu. System-drawn regular glass, radius about 20, 6pt inner padding, rows 44pt, 17pt text, leading checkmark column on the current choice, hairline separators between groups, destructive items last in red with a symbol. Optional small title (the label prop). The menu is native: draw only as a reference, do not rebuild it.

States. closed, pressed trigger, open, disabled (40%), long value truncates in the row.

Slider

Purpose. Pick a value on a continuous or stepped range (confidence threshold, playback speed, voice volume). Native SwiftUI Slider through @expo/ui. No Praci slider component exists yet; add one beside native-switch.ios.tsx.

Anatomy. Track 6pt tall, capsule ends; filled part ink #F1F0EB, remainder #3A3935. Resting knob: 28pt light circle with a soft shadow. Row height 44pt (full target). Optional min/max labels 13pt muted, current value 15pt tabular right of the label.

Dragging. The knob grows into a 56 x 34pt glass lens that refracts the track under it. This is the one place glass sits in a control knob while a touch is held (transient control exception); it returns to the solid circle on release. The value readout stays visible above the thumb's reach, not under the finger.

States. default, dragging, focus, disabled (40%), stepped (tick marks), empty (value at minimum: no fill).

Unconfirmed. The exact iOS 26 thumb dimensions and lens material; this sheet's numbers are approximations.

Stepper

Purpose. Nudge a small integer (retries, count, hours). Native SwiftUI Stepper through @expo/ui. No Praci component yet.

Anatomy. Capsule 96 x 36pt (each half 48 x 36, hit slop to 44), flat fill #2A2927, 1pt divider 18pt tall, minus and plus symbols 18pt. Label and current value sit in the row to the left; the value uses tabular numbers. Stepper is a control in a content row, so it is not glass.

States. default, pressed half (12% white), at minimum (minus disabled), at maximum (plus disabled), fully disabled (40%), focus. Press and hold repeats.

SF Symbols. minus, plus.

Do. Use it for ranges under about 10 steps. Don't use it to pick a date or an amount; use a field.

Badge and label chips

Purpose. Passive status or category labels on rows and headers. Web source: packages/ui-web/src/components/ui/badge.tsx (default, secondary, destructive, outline, ghost; h20, rounded-full, 8pt padding, 12pt weight 500). Mobile has no chip component; reuse the same variants.

Mobile sizes. Chip 22pt tall, 9pt side padding, 12pt label, optional 12pt leading symbol. Count badge: min 20pt wide, 20pt tall, 6pt padding, 12pt weight 600, tabular numbers. Unread dot: 8pt circle.

Mapping. Needs attention = neutral secondary, matching web InboxRow. Newsletter = secondary. Spam and Junk = warning tint (the only label chips that carry status color). Archived = outline. Count = primary fill for unread, secondary for plain totals. Bot identity chips use the bot color as a 6pt dot, never as the fill.

Layer. Content layer, flat fills, never glass. Not interactive; if a chip filters, wrap it in a button with a 44pt target and add a pressed state.

Contrast. All pairs at least 4.5:1; light warning text is darkened to #8A5A12 and light destructive text to #B91C1C.

Text field and search field

Text field. Single-line input in forms and sheets. Content layer: card fill #252523, 1pt input border #4A4944, radius 12 (base radius), 44pt tall, 14pt side padding, 17pt text (stops iOS zoom), label above 13pt muted, helper or error below 12pt. Always a real <label> plus input.

Search field. Floating control, so it is glass: capsule 44pt tall, magnifyingglass 17pt muted at 14pt leading padding, 17pt text. While typing, a 44pt xmark.circle.fill clear button appears trailing and a plain "Cancel" button slides in beside the field. Searching replaces the magnifier with a spinner. Inside a page body a search row may instead use the flat card fill.

States. empty (placeholder), focused (2pt #3B82F6 ring; caret not drawn here), filled, error (border #F46262, message with icon), disabled (45%), searching.

Do. Put the error message in text, not color alone. Don't put a field on glass unless it is the search field.

Hide-amounts eye toggle

Purpose. Masks money figures on Finance and Cap table screens for screen sharing and public places. Proposed on top of GlassIconButton with selected: no dedicated component exists yet. State is a per-device preference, applied to every figure on the screen.

Anatomy. 40pt glass circle (48pt target with slop), 17pt symbol. Visible amounts: eye, unselected, label "Hide amounts". Hidden: eye.slash, selected (primary fill, ink symbol), label "Show amounts". Expose as a toggle button (aria-pressed).

Masked figures. Replace each value with six bullets at the same font size, tabular alignment kept so rows do not jump; deltas and percentages mask too. Placeholders in this sheet use [AMOUNT].

Placement. Trailing in the page toolbar group, before More. Not repeated per card.

States. amounts visible, hidden, pressed (60%), disabled (no figures on screen), focus.
