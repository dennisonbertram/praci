Secondary pages: generation rules

One rule card per page in PG-B-*. The outer display is the base; inner and fold layouts derive from the same content.

Shared rules
  • Outer display: Island, time, Back group, action group, spacer, one prominent group at the bottom of a 60pt left strip. Content layer is the inset grouped list on #1C1C1A; glass only on the strip.
  • Inner book (890x626): 1/3 list or master (277pt, floating sidebar glass) + 2/3 detail; fold at x 435-455 stays empty and nothing interactive sits there.
  • Half-folded: split snaps to 1/2 + 1/2 (435pt each) with the same content as 1/3 + 2/3.
  • Laptop pose (626x890, fold at y 435-455): watch content on top, controls and lists below; horizontal bars are allowed. Pages marked not applicable are forms and keep the flat portrait layout.
  • Sheets: large and medium detents, inset 6pt, 34pt radius, grabber, more opaque at full height. Toggles are native switches (51x31, green when on). Light mode uses the same layout with light tokens.
  • Standard iPhone (393x852) is derived from the outer display: the same content column with a top bar instead of the side strip. Sheets, Artifacts, Legal and other pages not on PH-Pages are derived, not drawn. Pick one template per page. Drawn: Split, Inner, Inner-Message (List + detail); Desk, Desk-Computer (Live view + controls).

  • Posture changes keep the selection, scroll position and open thread. Folding to the outer display shows the thread, and Back returns to the page.
  • A notification opens that agent's thread, and Back goes to Home.
  • Ask [page] agent opens the thread in the right half (half-folded) or replaces the detail pane with Back to [page] (inner flat).
  • Always allow appears only for read-only tools; sending, paying or deleting asks every time.
  • Icons (SF Symbols): chevron.left, xmark, checkmark, plus, ellipsis, eye, arrow.clockwise, magnifyingglass, line.3.horizontal.decrease, text.bubble, doc.viewfinder, play.fill, folder, doc.
Agent settings
PG-B-BotSettings · bot-settings
Route / purpose
bot-settings.tsx. Edit one agent: name, title, description, color, voice, model.
Primary data
Agent record (name, title, description, color, voice flag, model, thinking level)
Components (DS sheet)
Lists (inset grouped, fields), Controls (switch, color swatch), Navigation (side strip)
Outer layout
Island, time, Back (chevron.left) group, spacer, Save prominent (text capsule). Content: large title Chat settings, grouped fields, Voice group, Advanced row.
Inner book 1/3 + 2/3
Chat or agent list in 1/3, settings form in 2/3 (max 560pt wide, left aligned)
Half-folded 1/2 + 1/2
Same form on the right half, thread stays on the left half; fold gap kept empty
Laptop pose
Not applicable (form, no watch content)
Accessible names
Back, Name this agent, Role, Color 1 to 7, Read replies aloud, Save.
Presentation
Push from the agent menu; Back returns to the thread
Empty / loading / error
Loading: skeleton rows. Error: red line above the toolbar action, fields keep input. Saving: prominent button shows spinner
Prominent action
Save (text capsule; shows a spinner while saving)
