# Brief: Integrations surfaces (mock demo data)

**App.** Rakazo is a founder's AI chief of staff. It has bots (agents) for inbox, finance, cap table and data room. Integrations is where the founder connects outside apps (Gmail, Mercury, Brex, Carta, Blockscout) and chooses which bots may use each one. The data is invented (company "Northwind Robotics", user "Maya Chen (Mock)").

**Persona.** A startup founder who knows what Mercury and Gmail are. She does not know what "MCP" means and has not thought about "agents" as separate from the chat bots she already uses. She wants one answer: "can the right bot use this app, and can it change things without asking me?"

**Pages.**
1. Integrations home: Connect apps list (Connected grid with a "Used by" row of bot avatars, Find an app, Popular, Finance, Social, Tools, Anything else).
2. Server detail page (Mercury, Brex, Carta): header, Create agent button, an Agent section with two switches ("Allow changes in X", "Only this agent"), a Used by list with one switch per bot, Remove.
3. Connected app detail (Gmail): accounts with Create agent per account, Used by switches, tools list.

**Viewports.** 1440x900 desktop, 768x1024 tablet, 375x812 phone. The app is dark theme, with a left sidebar of bots.

**What to judge.** Visual hierarchy, one primary action, consistency between the home tiles and the detail pages, whether labels make sense to the persona, spacing, alignment, target sizes, and whether switches that change what a bot may do are clear. Be harsh and specific; cite what you see in the screenshot.
