# UXV-3 Finance tiles hide their link — decision

Chosen: Finance tiles get the same hover treatment as the other integration tiles (the existing tile hover class) and a visible focus ring on the stretched name link; tile content uses the same vertical structure as the generic tiles so the status row lines up across a row (Coinbase included).

Rejected: adding an extra "Manage" button (another button in an already crowded slot, INT-2).

Acceptance: hovering a Mercury, Brex or Blockscout tile changes its background like a Connected app tile; Tab to the tile name shows the focus ring; badge rows in one grid row share the same y within 2 px at 1440.
