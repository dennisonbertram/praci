# J2 proposal B: restructure (context-dependent prominent, fewer controls)

The prominent action is the verb of the current view, and the agent is the way to do it.

- List: prominent = Ask Inbox agent. Message view: prominent = Reply, which opens the Inbox agent thread with "Reply to Ana:" prefilled and the message attached, so the agent drafts. A manual compose is a menu item.
- Strip set: Back; Search, Filter; spacer; More; prominent. Compose is removed from the strip and moves into More with Cleanup (More: Compose, Cleanup).
- Message view strip: Back; Archive; spacer; More (Forward, Compose, Cleanup); prominent Reply.
- PH-Inbox: Back | spacer | [Search, Filter] | More | prominent Ask. Two icons in the actions group, so the bar is calm.
- Split/Sheet: same, with Hide amounts and Important only removed.
- Inner: Reply/Ask hands straight into the thread already open.

Cost: medium. Changes the prominent on the message view, removes a control that mail users expect, and needs a hand-off contract (Reply prefill).
Risk: writing a new mail takes two taps and a menu scan. Reply being the same icon on two different screens with different meanings is confusing.
