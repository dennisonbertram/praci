# Judge brief: J2 (round 2, cluster C4) Compose: Send in every frame, one close sheet

Context: Praci's planned native SwiftUI iPhone app. Board PG-A-Compose is the Duo outer display (466x678) with a left side strip. Rules: glass only on floating controls, exactly one tinted prominent action per view, at most three glass groups, product name Praci.

Problem: In the Edit draft, Cc suggestions, Invalid address and Discard prompt frames the Send arrow is replaced by a "Done" capsule. A draft reopened from Drafts then has no Send, and "Done" does not say whether it saves, closes or sends. Done also stays enabled on an invalid address. Two different close-with-edits sheets exist: "Discard changes / Keep editing" and "Save draft / Discard draft / Cancel".

Acceptance: Send appears in every compose frame; no unexplained Done; one close sheet; Send is dimmed for no recipient or invalid address; the agent-draft journey stays at 3 to 6 actions with no dead ends.

Proposals:
A: delete Done, draw Send everywhere, dim Send on invalid. One sheet shown on X only when changed: Save draft / Discard / Keep editing.
B: Send everywhere; no sheet at all; autosave on X with a "Draft saved / Delete" toast on return.
C: Apple Mail pattern: Send everywhere; sheet only when changed with two actions (Save draft, Discard draft) and the scrim to keep editing.

Score each 1-5 on: meets criteria x3, simplicity x2, consistency x2, usability x2, visual quality x2, effort/risk x1 (5 = small and safe). Return a winner, optional graft, and a short defense.
