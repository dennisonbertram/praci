# Judge brief: J2 Inbox prominent action and control set

Praci is a planned native SwiftUI iPhone app with Duo outer display (466x678, side strip), standard iPhone (393x852), and inner split layouts. Rules: glass only for floating controls; at most three glass groups plus one tinted prominent action per view; icon-only buttons with accessible names; the persona is a founder triaging mail with an Inbox agent that drafts replies.

Problem: PH-Inbox tints Compose and has no route to the Inbox agent or Cleanup; the outer and inner boards tint Ask Inbox agent. Choose the one prominent action, the control set, and where Cleanup lives.

Option A: Ask Inbox agent is prominent on list and message. Strip: Back; Search, Filter, Compose; spacer; More (Cleanup); prominent Ask. Reply is a plain action on the message view.
Option B: Prominent is Ask on the list, Reply (hands to the agent with a prefill) on the message. Compose moves into More beside Cleanup. Actions group is Search, Filter only.
Option C: Apple Mail convention. Compose is prominent on the list, Reply on the message. Search field becomes "Search or ask Inbox agent". More holds Cleanup.

Score each option 1-5 on: meets acceptance, simplicity, consistency, usability, visual quality, effort and risk (5 = small and safe). Return a winner, an optional graft, and a short defense.
