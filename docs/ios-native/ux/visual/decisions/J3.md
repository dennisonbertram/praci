# J3: Mail draft card editing model

## Problem
The Save/Send card has no edit entry (STORY-047-R1-1, F-thread-012, V-thread-R1-5), "Save" does not say what it saves (V-iphone-R1-12), the old card has no state after the agent replaces it (STORY-047-R1-3), Cc suggestions and invalid-address states are not drawn (STORY-047-R1-4), Save, empty-To and abandoned edit have no outcome (STORY-047-R1-6, V-inbox-R1-10, F-inbox-computer-R1-002), and it is unstated whether Compose X and card Save write the same draft (RED-R1-10). Evidence: PG-A-Thread, PH-Thread, Inner (card with Save and Send), PG-A-Compose (X and up-arrow, no draft mode), DS-06-Chat ("Body is tappable to edit").
Acceptance: an edit entry on the card; a prefilled editor whose commit is not the send arrow and that returns to the card; "Replaced" state; one meaning for save; one draft record; Cc suggestions, invalid address, empty To and discard-with-changes drawn; one tinted prominent action.

## Options considered
Weighted scores (max 60) per lens: usability / visual / engineering. External: Muse / Argon.
| Option | Idea | Lenses (U / V / E) | External (Muse / Argon) |
|---|---|---|---|
| A Minimal | composer is the only editor; Save becomes Save draft; Replaced; Compose X Save/Discard | 39 / 41 / 43 | 31 / 31 |
| B Restructure | body tap opens prefilled sheet with Done; card keeps Save draft and Send | 46 / 48 / 46 | 39 / 37 |
| C Mail pattern | draft is autosaved, Save removed; footer Edit + Send; Edit or body tap opens the sheet; Done; X with changes asks | 55 / 55 / 52 | 54 / 59 |

A fails criterion 1 (no edit entry, no Cc picker), so it is disqualified on its own.

## Decision
Option C, with the "Edit draft" sheet title (from B) already included. Details are in the edit list below and proposals/J3/C.md.

## Why this is the best
- Against A: the founder must describe a one-word fix to the agent, wait for a model round trip, and cannot pick Jordan Lee from a contact list. It fails the edit-entry criterion.
- Against B: two commit points (Save draft on the card, Done in the sheet) mean two kinds of save; the entry is a hidden body tap; Replaced and Compose-X equivalence are left open.
- Norms: one prominent action (Send); native sheet and confirmationDialog; fewest words (Save removed, no explainer copy added); concentric corners reuse the existing card and capsule radii.
- Costs: needs a server decision that every agent draft is stored as a draft record on creation and on each edit. Not confirmed in this repo; flagged for the owner. Edit is dimmed while the agent is working so a rewrite cannot overwrite an edit.

## Rebuttal
External judges agree (both pick C). Their only differences are lower effort scores, which match the risk note above. No rebuttal needed.
