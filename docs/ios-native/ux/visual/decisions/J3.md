## Decision
Option C, no changes from the external judges' graft (see rebuttal).
1. Running composer: Stop holds the trailing slot for the whole run. Typed text and attachments stay as a draft; nothing sends by itself. When the run ends or is stopped the slot becomes the Send arrow with the draft intact. No caption.
2. Reactions ship. Long press on a bubble shows a six-emoji glass row (thumbs up, heart, laugh, surprised, sad, folded hands) and a menu with Reply and Copy only. The row is the picker, so the "React" item goes. Tapping the chosen emoji again removes it. The chip sits under the bubble.
3. Archive pops to Home. A solid bottom bar toast reads "<Name> archived" with Undo (no second line). Undo restores the Home row and stays on Home. Menu item: "Archive agent" in a one-agent chat, "Archive group" in a group, matching Settings "Archived agents".
Grafts: Messages' removal of a separate React item and Mail's list landing come from pattern C itself; the "no second toast line" comes from Inbox's toast; no ideas adopted from B.

## Why this is the best
- Against A: A leaves two ways to react, never shows Send returning (the founder sees only a dead composer), and keeps "chat archived" against "Archived agents".
- Against B: a queue needs backend ordering and cancel that no contract states, puts two controls in the trailing slot, and removes a reaction feature the contract already supports.
- Norms: one tinted action per view (Stop or Send, never both), solid toast bar (no new glass), emoji row and menu are the only two glass groups in that frame; draft safety (no auto-send of half-typed text).
- Costs: one added frame, four Archive frames redrawn from Home markup. Left open: where an archived group is listed (Settings "Archived agents" is agents only) and the Clear chat item (RED-R3-11 second half) stays as drawn.

## External judges
Both chose C. Both suggested the same graft: skip the extra "Run finished, draft kept" frame. Rebuttal: V-thread-R3-1 complained that the user has no visible Send, and this frame is the only place the Send arrow with the held text appears; it is a different state, not a second drawing of the running composer, so the "drawn once" acceptance holds. It costs one frame. If it is cut, DS-06 must still state the rule in words.
