# J4: Home roster and section noun

## Problem
Finance agent and Legal agent appear only in Activity (they have tasks), so without recent work they have no row on Home (V-iphone-R3-8, RED-R3-2). The section is called PERSONNEL but holds agents and one group, while the New menu, the New agent sheet and the empty state ("No agents yet") say "agent" (V-home-R3-13, STORY-085-R3-7). The group member picker on PG-B-NewGroup lists only four agents, so Carta, Mercury and Brex agents cannot join a group (F-thread-016 area). Boards: PG-A-Home, PH-Home, Main, PG-B-NewBot, PG-B-NewGroup (frames viewed in `scratchpad/r3` screenshots).

Acceptance used for scoring: every agent and group has a Home row; one noun for the section matching the New agent menu and empty state; Pages stay reachable on 393x852 and 466x678; no new copy unless it does work; recency sort unchanged.

## Options considered
Weighted score = 3 x criteria + 2 x (simplicity + consistency + usability + visual) + effort; max 60. Detail in `proposals/J4/A.md`, `B.md`, `C.md`.

| Option | Idea | Usability | Visual | Engineering | Muse Wonder | Gemini 4 Argon |
|--------|------|-----------|--------|-------------|-------------|----------------|
| A Minimal | Rename to AGENTS, list all 7 rows | 45 | 45 | 49 | 42 | 58 |
| B Restructure | RECENT (4) plus Agents page row and new screen | 36 | 40 | 32 | 33 | 28 |
| C Pattern | AGENTS, 4 recent plus unread, inline "Show 3 more" (Things, Mail Show More) | 55 | 53 | 49 | 53 | 46 |
| Total of all five columns | | | | | | A 194, B 142, C 202 |

## Decision
Option C. Section label AGENTS everywhere PERSONNEL appears. The list contains every agent and group in recency order. Collapsed, it shows the four most recent rows plus any row with an unread dot, then one plain row "Show N more" (secondary text, chevron.down); it expands in place and turns into "Show less". With four agents or fewer no extra row appears. Finance agent and Legal agent are in the list even with no task; Activity stays a copy of attention rows. Groups stay in AGENTS. NewGroup lists every agent.

Grafts: from Argon's graft, unread rows are never hidden by the collapse (already part of C). From A, no new component: the row reuses the See all affordance style.

## Why this is the best
- Against A: seven agents plus a group make eight rows and push PAGES fully off the 466x678 Duo outer display and past the fold on iPhone; the count also grows with each agent the user creates. C costs one 44 pt row and bounds the list.
- Against B: it adds a second noun (RECENT), a new route and a third-tap path to quiet agents, files Agents among Pages, and needs new frames and stories for a seven-item list.
- Norms: one noun across menu, sheet, empty state and section; solid content, no glass; no new prominent action; native `List` section; no new screen.
- Costs: one extra tap for agents below the fold (Finance, Legal, Brex); the expanded state must be drawn.

## Rebuttal to external judges
Muse Wonder agreed with C. Gemini 4 Argon chose A because 7 rows is small and nothing is hidden in a static mockup. The argument holds only for today's seven agents: the roster grows by every New agent, collapse saves two rows now and more later, and on the Duo outer display even A's first screen leaves no Pages visible. Argon also called C a "compact-height fallback" worth adopting, and rated it a close runner-up (4 on usability, visual, effort). The unread-never-hidden rule answers its concern that an important agent is concealed.
