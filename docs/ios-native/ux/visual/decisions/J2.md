# J2 (round 3, cluster C3/C6): Cleanup entry and the archive versus unsubscribe confirm

Note: this file replaces the round 2 J2 write-up (Compose Send), which used the same label for a different cluster.

## Problem
Cleanup is a labeled capsule in the PG-A strip (PG-A-Cleanup frame 1) but sits in the "..." More menu on PH-Inbox, Split and Inner-Message, and Sheet draws no entry at all. The only confirm, "Clean up 3 senders? Archive and unsubscribe", joins a reversible action (Archive, Undo works) with an irreversible one (Unsubscribe), so a user cannot archive without unsubscribing (STORY-062). The chevron holds one unexplained item, "Skip inbox for future mail" (V-inbox-R3-4, -5, -6, RED-R3-5, RED-R3-18).
Evidence read: r3/PG-A-Cleanup.png, r3/PH-Inbox.png, r3/Split.png, r3/Inner-Message.png, problems.md C6 acceptance: separate confirms; Undo offered once; Skip inbox explained or removed; one entry location on every board.

## Decision
Winner: A, with two grafts.
1. Cleanup lives in the "..." More menu on every inbox board. PG-A-Cleanup swaps its labeled capsule for the "..." circle.
2. Two native confirmation dialogs: "Archive 101 emails?" (Undo brings them back) and "Unsubscribe from 3 senders?" (can't be undone, destructive button). The combined confirm is deleted.
3. "Skip inbox for future mail" and its chevron are removed; no board explains it and nothing else uses it.
4. Graft from C (both external judges named it): after Archive, the Done view offers "Unsubscribe from 3 senders", because archived senders leave the list and a user who wants both would otherwise have to find them again.
5. Graft from C: Undo is offered once, on the Done view. The long paragraph about both outcomes is replaced by one line each.
Visible default for the inner display: none. Cleanup is a monthly task; Apple Mail keeps rare list actions in "..." and Inner-Message already draws it there. A permanent capsule would add chrome (README: at most three glass groups, one prominent action).

## Why this is the best
- Against B: adds a glass capsule to bars with no room (PH-Inbox bar already has four buttons plus Ask), and costs chrome on every inbox view for a rare task.
- Against C: C is a good pattern but skips the Archive confirm that the acceptance requires, and both external judges and the criteria score rank it lower. A bulk archive of 101 emails across three senders is larger than a Mail swipe, so one confirm is defensible; the confirm states the count and the Undo.
- Costs: a user who wants both does select, Archive, confirm, Unsubscribe, confirm (5 actions after selecting) versus 2 today. The Done-view follow-up keeps this to a single screen.
- External judges agreed (A, A); no rebuttal needed. The one reservation, that an Archive confirm duplicates Undo, is accepted to meet the acceptance line.
