# Brief: Home and creation screens (round 1)

Praci is a planned native SwiftUI iPhone app (Liquid Glass) for startup founders. People chat with a team of AI bots (Chief, Finance agent, Legal agent and others), read an inbox, and open pages such as Finance and Legal. The boards are static mockups for the iPhone Duo outer display (466x678 pt, controls in a side strip next to the Dynamic Island).

Persona: a first-time founder, non-technical, opening the app on a new account, then every day to see what needs attention.

Screens and the step each serves:
- PG-A-Home: daily landing. See inbox count, bot activity needing approval, pages, and the list of bots; pick one.
- PG-A-HomeNoModel: first run. The user must connect an AI model before any chat works, then continue.
- PG-B-Spaces: switch space from the title menu, and edit space settings.
- Main: older Home/Inbox mockup on the outer display.
- PG-B-NewBot: create a bot (sheet).
- PG-B-NewGroup: create a group chat of bots (page).
- PG-B-NewSpace: create a space, shown in its error state (sheet).
Rules: glass only on floating controls, solid content, one prominent action per view, 44 pt targets.
