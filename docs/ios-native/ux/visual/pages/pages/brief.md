# Brief

Praci is a planned native SwiftUI iPhone app (iPhone Duo outer display, 466x678 pt, controls run down a side strip beside the Dynamic Island). Praci is an AI "startup OS": a founder talks to bots (Chief, Inbox agent, Finance agent, Legal agent) that read mail and finance data, keep pages, run routines, and use a shared Team Computer. These are static design boards, not live screens.

Persona: a first-time founder with a small team who wants to check runway, contracts, the cap table and files, read what the bots made, and tune a bot or group, in the fewest taps, without jargon.

Screens and the step each serves:
- PG-B-Finance: check runway, cash, burn, accounts, upcoming bills.
- PG-B-Legal: see contracts and deadlines.
- PG-B-CapTable: see ownership from Carta.
- PG-B-DataRoom: find a file.
- Desk: laptop-pose Finance page above a chat with the Finance agent.
- PG-A-Computer: watch and take control of the shared Team Computer.
- PG-A-AgentPage: read the Finance agent's Runway summary page.
- PG-A-AgentList: work through a checklist page.
- PG-A-Artifacts / PG-A-Artifact / PG-A-Image: browse, open and view things bots produced.
- PG-A-Routine: inspect a weekly scheduled bot run.
- PG-B-BotSettings / PG-B-GroupSettings: edit a bot or a group.

Judge: does the user know where they are, what to do next, and can they get there in few taps. Rules: glass only on floating controls, solid content, one prominent action per view, 44 pt targets, concentric corners.
