# Visual findings: account and settings boards (round 2)

Boards: PG-B-SignIn, PG-B-SignUp, PG-B-ForgotPassword, PG-B-Server, PG-B-Account, PG-B-Settings, PG-B-Models, PG-B-Voice, PG-B-Integrations. All are 466x678 Duo outer-display frames, now multi-frame grids. Audits: audit.json. Second opinions: second-opinion.json (muse = meta/muse-wonder, argon = google/gemini-4-argon; PG-B-Settings was not sent to them, I judged it myself). Every external claim kept here was checked against a screenshot in shots/.

Audit notes: no page scroll, no overflow, no low contrast. The 19-21 pt "small target" hits on inputs are false positives (each sits in a 44 pt row). Every button and link measured is 44 pt tall or more; only the segmented control on Server integrations is 30 pt (platform standard is 32, so not a finding). Off-scale spacing (6/10/14) is the shared board grid. Rejected external claims: that alerts are not centered in the strip and overlap the side strip (they are centered in the content strip and clear of the side strip); that text links are under 44 pt (measured at 44 or more); the high severities muse and argon put on disabled-looking primary buttons on empty forms (validate-on-tap is a valid iOS pattern, so I kept only the error-frame problem). Round 1 items now fixed: Settings values (no more "[N]"), delete-account disabled state and password/SSO/code variants, Voice single "In use", Server Retry and Save states, Sign-in specific error states.

## Excellent as is

- PG-B-SignIn: eight states (error, loading, load failure, session ended with "Unsent drafts are kept", system SSO prompt, cancelled, long provider name) and a single tinted Sign in per view.
- PG-B-Server: validation ladder (invalid, checking, http warning in amber, not Praci, unreachable with Retry) and the red Switch confirmation that states what is lost.
- PG-B-Account: staged delete with disabled Delete until input, password, SSO and emailed-code variants, a Deleting overlay and an After delete landing.
- PG-B-Settings: root rows now show real values (Model A, Device, 2); root uses a close X and sub-pages a back chevron; Archived bots has an empty state; shipped avatar shapes appear on archived bots.
- PG-B-Voice: fallback states for hosted not set up, not connected, device unavailable, and denied microphone with Open Settings.
- PG-B-Integrations: connectors use letter tiles, a Pending state, and an error with inline Retry; Models shows a menu, a confirmation line and provider states.
- All boards: glass only on the side-strip controls, solid content, concentric corners, 44 pt targets, the name Praci.
