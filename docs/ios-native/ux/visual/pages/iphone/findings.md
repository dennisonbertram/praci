# Visual findings: iPhone boards, round 3

Boards: PH-Home, PH-Pages, PH-Thread, PH-GroupThread, PH-Inbox, PH-Computer, PH-Spaces. Every frame of each grid was judged against its screenshot in `shots/` (scratch, not committed). Audits are in `audit.json`; second opinions in `second-opinion.json` (both models ran). Found by: [own] my reading of the screenshot; [muse] Meta MUSE Wonder; [argon] Gemini 4 Argon. "Verified" means I checked the claim against the screenshot or the DOM.

Audit summary: boards are multi-frame grids wider than the 393 pt viewport, so page scroll and overflow numbers are not meaningful. The audits found no low-contrast text except the emoji reaction chips on PH-Thread (a translucent menu; ignored). A DOM measurement of PH-Inbox shows Back, Search, Filter, Compose, More at 44 x 44 and Ask at 80 x 44, so the claim that the Inbox icons are about 36 pt is rejected. Off-scale spacing values: Home and Spaces 3, 6, 7, 9, 10, 14, 18; Pages 5, 6, 10, 14; Thread 6, 9, 10, 14, 18, 22; GroupThread 5, 6, 10, 14, 22; Inbox 6, 10, 14; Computer 6, 10, 14, 18, 22. PH-Pages uses ten distinct font sizes.

Round 2 findings now fixed (checked in the screenshots): stale Personal data under Northwind (all sections now skeleton), Send enabled during "Updating" (now disabled), GroupThread header gutter, no-model triple copy, Personnel order and Inbox agent subtitle, Inbox toasts moved to the bottom, Inbox recovery and compose hierarchy (Compose is the prominent icon, Ask is labeled), Clear and Delete confirmations drawn, Computer error cause stated, Consent declined frame drawn.

## Excellent as is

- PH-Home Connected: Activity first, "Needs you" amber badge on the approval row, one prominent New button, clear section labels.
- PH-Home No model: one button, one sentence of purpose, no repeated copy.
- PH-Spaces switching frame: every section is skeleton, so no data from Personal appears under Northwind.
- PH-Thread: Clear and Delete confirmations with plain consequence copy; Send disabled while the agent edits or the recipient is empty; the failed-attachment frame says how to fix it.
- PH-Inbox: Compose is the one prominent toolbar action, Ask is labeled, toasts sit at the bottom near the thumb, every error and consent state has a recovery button, and all icon targets are 44 pt.
- PH-GroupThread: header gutter fixed; menu, both confirmations, and Undo are drawn.
- PH-Computer: every control state is drawn, with plain failure copy ("Network lost. Check your connection, then retry.").
