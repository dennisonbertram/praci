# Brief: Praci iPhone boards, round 3

Praci is a startup operating system. A founder talks to AI agents (Chief, Finance, Legal, Inbox, Carta, Mercury) that read mail, watch money, and draft work. Anything an agent would send or pay needs the founder's approval. This is a planned native SwiftUI iPhone app; the boards are static dark-mode mockups at 393x852 (PH-Computer at 810x882). Each board is a grid of labeled states.

Persona: a busy non-technical founder, one hand, on the move, who wants to know what needs them and to act in the fewest taps.

Screens and the step each serves:
- PH-Home: landing. See what needs me (Activity), jump to Inbox, an agent, or a page; switch space; start something new. Includes a no-model state.
- PH-Pages: Finance page and Settings. Read runway and accounts, ask the agent; change settings.
- PH-Thread: one-to-one chat with an agent; approve or edit a drafted email; attach files; chat menu with confirmations.
- PH-GroupThread: chat with several agents at once; menu with confirmations.
- PH-Inbox: triage mail, swipe to archive, recover from errors, grant consent.
- PH-Computer: watch, take over, and release the shared team computer the agent drives.
- PH-Spaces: switch between spaces (Personal, Northwind) and see loading.

Rules: glass only on floating navigation and controls, at most three glass groups per screen, one prominent action per view, solid content, 44 pt targets, product name Praci.
