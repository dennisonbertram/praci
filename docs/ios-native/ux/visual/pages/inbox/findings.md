## Claims rejected after checking
- Muse: Send "remains active" beside Send again in the unknown-result frame. The screenshot shows it dimmed.
- geometry-audit "wrappedControls" on Compose buttons. The screenshot shows single-line labels; false positive.
- geometry-audit small target `input#sm` (20 pt) on Split. The visible search field is about 38 pt high.
- Argon: Cleanup has no select-all. True but low value; not filed.

## Excellent as is
- Cleanup states are complete (nothing selected, ticked, confirm, in progress, failed, done, empty, history) with plain copy: "Couldn't archive. Nothing was moved."
- Undo after Archive, and Undo with a history list in Cleanup.
- Inbox recovery states (inbox zero, mail changes off, Gmail needs reconnecting, no account, consent, first sync) each name the cause and offer one action.
- Compose error states say what happened and where the mail is ("Your message is saved in Drafts").
- Message reading view: solid content, generous type, attachment rows with size.
- Unsubscribe confirm states that it can't be undone.
- Touch targets: no target under 44 pt on any board (audit.json smallTargets).
- Glass limited to the strip, menus and toasts; content is solid.
- Inner display adaptation: the list plus the message in Inner-Message keeps the persona oriented.
