# Visual findings: thread boards, round 3

Boards: PG-A-Thread, PG-A-ThreadStates, PG-B-Consent, PG-A-GroupThread, Inner, DS-06-Chat. Screenshots are in `shots/` (scratch, not committed; `ts_row0-5` are crops of ThreadStates, `ds_0-8` are crops of DS-06). Audit output is in `audit.json`. Second-opinion output is in `second-opinion.json` (muse-wonder and gemini-4-argon both ran; the argon text was cut off by the tool at about 9,000 characters, so its last findings were not read). Tags: [own] my observation, [muse], [argon]. Every external claim was checked against a screenshot before it was accepted.

Audit notes: PG-A-Thread, ThreadStates, Consent and GroupThread have no horizontal overflow at the viewport I set (the tall boards scroll vertically by design). The "unevenRows" and "wrappedControls" flags are false positives (label/value pairs). GroupThread reports five 6 px spills that I could not see in the screenshot. The only low-contrast control measured is DS-06 "Deny" (4.13:1). The audit's small-target check found only two API key inputs in DS-06 (19 px tall).

## Fixed since round 2 (verified by eye)

Send is dimmed while the agent updates a draft, and for an oversize or failed file. The offline banner stays when a message is queued. "Sends after run" is drawn beside typed text during a run. Delete, Clear and Archive now have the right treatment in both the single and group thread (confirmations for the irreversible ones, Undo for Archive). First-message suggestion chips are outlined. DS-06 draws Attach inside the capsule, Dictating uses a stop glyph, "Needs approval" is a pill, and the MCP amount is the largest text on its card. The "Needs approval" jump pill is centered above the composer. The consent board now draws "Not now" and a model-sharing-off gate above the composer.

- Failed and Refused states: red outline on the bubble only, cause in words, one adjacent recovery action (Retry, Remove file).
- Offline frames: the banner persists with a queued message and the bubble says "Waiting to send".
- Approval scrolled away: one centered pill returns the user to the pending draft.
- Running controls: working avatar with ring, Stop in the trailing slot, Send hidden while the card owns the prominent action.
- Group thread: sender name above each bubble, shipped avatar shapes and colors, delete confirmation states scope and irreversibility.
- Destructive confirmations in both threads: Clear and Delete state what is removed and what stays.
- Consent: one ink Allow, quieter Not now, one plain data sentence; "Not now" outcome drawn; Settings shows the dependency note.
- Exactly one prominent action in every frame checked (Send, Stop, Take control, Sign in, Allow, Turn on).
- DS-06-Chat spec: layers stated (glass vs content), money amount as the largest text, no Always allow for money tools, resolved MCP row keeps amount and recipient.
