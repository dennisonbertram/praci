# Visual findings: thread boards, round 2

Boards: PG-A-Thread, PG-A-ThreadStates, PG-B-Consent, PG-A-GroupThread, Inner, DS-06-Chat. Screenshots are in `shots/` (scratch, not committed). Audit output is in `audit.json`. Second-opinion output is in `second-opinion.json`. Tags: [own] my observation, [muse], [argon] second-opinion models; every external claim was checked against a screenshot first.

Audit notes: PG-A-Thread, PG-A-GroupThread, PG-B-Consent and Inner have no page scroll or overflow at their own size. PG-A-ThreadStates and DS-06-Chat are taller or wider than the viewport I set, so their scroll and overflow numbers are not defects; the full screenshots are correct. The "wrappedControls" flags are false positives. The audit found no small targets except "Privacy details" (86 x 17), and low contrast only on DS-06-Chat ("Needs approval" 3.64:1, "Deny" 4.13:1).

Fixed since round 1 (verified by eye): Stop button while the agent runs, working indicator with bot avatar, refused attachment shows file and "Remove file", full rail in all thread states, user bubble distinct from agent bubble, resolved MCP row shows amount and recipient, "Always allow" removed for money tools in the spec, placeholders replaced by invented figures, Needs approval is a pill on the thread boards.

## Excellent as is

- Mail approval card on the thread boards: recipient, body, one ink Send, Edit secondary, status as a word in a pill; Empty recipient blocks Send and says why in the field.
- Failed and Refused states: red outline on the bubble only, the cause in words, one adjacent recovery action (Retry, Remove file).
- Running controls: working avatar with ring, Stop in the trailing slot, Stopping spinner, Send hidden while the card owns the prominent action.
- Group thread: sender name above each bubble, shipped avatar shapes and colors, Delete confirmation states scope and irreversibility.
- Consent sheet hierarchy: one ink Allow, quieter Not now, one plain data sentence; Settings shows the dependency note.
- Inner two-pane layout: list and thread fit one screen with no scroll; Needs reply rows now carry weight and dot.
- DS-06-Chat spec: stated layers (glass vs content), stop rule, money tools never offer Always allow, resolved MCP row keeps amount and recipient.
