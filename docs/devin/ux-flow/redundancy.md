# Devin page: redundancy and information architecture critique

Scope: the planned read-only Devin page with a docked Devin agent. Rakazo never launches, replies to, or stops Devin sessions.

Evidence read: `docs/devin/ux-paths/catalog.md` (sections 7 and 8, and the stories cited below), `docs/devin/mockup.html`, the mockup screenshots (`mockup-v2-full.png`; the dark variant was not opened), the existing-app reference screenshots (`legal_page.png`, `captable.png`, `integ_with_connections.png`, `sidebar_pages_added.png`, `activity.png`, `sidebar_glance.png`) and `apps/web/src/pages/ActivityList.tsx`. Heuristic numbers refer to `simplification-heuristics.md`. The catalog's own section 7 is the lead list. Where this document disagrees with it, it says so.

What the mockup actually shows (observed): header "Devin" + "Updated 1m ago" + an external-link icon + "Ask"; four tiles (Needs you 2, Working 2, PRs open 3, ACUs this week 41.6); one flat table with columns Session, Status, Pull request, From, ACUs, Updated; a sidebar dot on "Devin"; a docked "Devin agent" panel whose sample question is "What is Devin stuck on?". The table has no group headers, so "status badge text vs group header" is not an issue in this mockup.

## Top 5 recommendations (ranked)

1. Remove "Allow changes in Devin" and its write tools and skill pointer for Devin (OF2, P8). It contradicts the read-only promise and is a blocker in the catalog (GAP-10).
2. Cut duplicated numbers: drop the PRs open tile and the ACUs tile, give the sidebar dot no number, and show the header "Updated" only when data is stale (I1, I4, I5, I9, H6). This leaves one canonical needs-you count.
3. Define the dot as "a session is Needs you" rather than "unseen notification" (I2). Today it clears on first visit while two sessions still wait (STORY-016), and a toast and push are not a record.
4. Align naming with the app: "Needs input" for the row status and "Needs you" for the group or count, "Source" instead of "From", "session" for items, "Devin" page and "Devin agent" panel as with Legal (H2, H3, H4, H5).
5. Make the panel earn its place: change the sample question so it is not "What is Devin stuck on?" and fix the unlabeled header icon, the Integrations "Open Devin" link, and the "repo docs" subtitle so each route and promise has exactly one meaning (OF1, OF3, P2).
