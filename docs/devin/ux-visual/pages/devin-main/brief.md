# Brief: Devin page mockup (static HTML, Rakazo)

App purpose: Rakazo is a founder-facing app. The Devin page is a read-only view of what the founder's Devin coding agent is working on: sessions grouped into Needs you, Working, Earlier, with status, pull request, source and last update. Rows that need an answer link out to Devin ("Answer in Devin"). A docked chat panel (the "Devin agent") answers questions about the sessions.

Persona: a busy founder, not an engineer, glancing at the page between meetings to learn "does Devin need me, and what is it doing?". Mobile use is common.

Shown: the main page with the agent panel open (1440 wide, light), first visit with panel closed (dark), the same page at 375 wide (list layout), the panel overlay at 768 wide, a key-rejected stale state, loading skeleton, empty state, not-connected state.

Constraints: the app is monochrome (ink primary, status colors only for meaning). Reference app pages (Legal) use 4 KPI tiles, a table with status pills, and a page header with actions on the right.

Judge as a ruthless senior product designer: hierarchy, density, whitespace, state completeness, clarity of status, accessibility, mobile layout. Name concrete problems with locations.
