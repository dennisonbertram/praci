# Brief

Audit these screenshots of a static mockup of the "Devin" page of Rakazo, a founder-facing app. Scope: the docked "Devin agent" chat panel (transcript, tool-activity rows, composer, header), the "Connect Devin" API-key dialog, the "Devin has a question" notification toast, and the sidebar link with a dot. Files named real-* are the real app's equivalent components (Storybook); everything else is the mockup.

Be a ruthless senior product designer and a first-time user. For each screenshot list concrete visual or usability problems: hierarchy, spacing, alignment, density, clipping or overflow, contrast, touch target size, inconsistency with the real equivalents, missing states, confusing copy. Name where on screen each problem is. Note every visible difference between the mockup and its real equivalent. Rate each P0 (misleads/blocks), P1 (a person stumbles), P2 (below excellent), P3 (polish). Do not praise. Do not invent problems you cannot see.
