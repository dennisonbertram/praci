Notes (not part of the UI)

  • Entry point. The existing Ask agent button. Today it calls inbox.askAgent and navigates to the chat of a per-conversation agent (spawn key from the mail thread). In this design the same agent opens in the panel and "Open in chat" goes to that chat. One agent per thread, so the panel and the chat share history.
  • Draft to composer. "Reply with draft" sets the composer seed to a reply with the draft text as the body. The user edits and sends through the normal send flow; mail_send keeps its approval rules. The agent never sends on its own.
  • Starts automatically when the panel first opens on a thread; reopening shows the saved answers. Phone: the same panel as a sheet.
